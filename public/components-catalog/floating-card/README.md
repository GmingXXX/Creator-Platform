# 浮光 · 3D 成果卡片

来源与适配记录见 source.json；upstream.tsx 与 upstream-demo.tsx 为取得的原始组件代码。运行版本使用原组件的结构和交互逻辑，改写为自包含 HTML/CSS/JavaScript，移除 React、Tailwind、图标和其他运行时依赖，并替换为虚构企业内容与本地示意图片。

打开 index.html 可独立体验；上传 ZIP 到智创可检查、预览与参数试编辑。没有安装额外依赖，网络图片仅在用户主动填写图片地址后使用。

当前预览来自本目录 index.html 的实际浏览器截图。原作者署名与来源应保留；原始代码与平台目录的许可条件须随商业分发一并核对。
