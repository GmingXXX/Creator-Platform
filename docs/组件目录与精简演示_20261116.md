目录位于 `public/components-catalog/`。每个目录保存上游源码、适配来源记录、独立运行 HTML、参数清单、实际截图及完整 ZIP。上游 React/Tailwind 依赖已在适配版中替换为自包含 HTML/CSS/JavaScript；原始版本保留供追溯。预览图由该目录的运行 HTML 在浏览器中直接截图，未使用无关占位封面。

社区可以预览、下载完整 ZIP、检查与试编辑。保存试编辑结果产生个人副本，不改变原社区资产；副本保留参数值与运行 HTML，能继续下载和插入交互页面画布。内部元素按已开放参数编辑，不承诺自动拆成原生画布节点。

## 演示输入

可手动上传的精简资料包：`output/智创精简演示输入_20261116.zip`。

- 企业大事记：一份文本、三张已有示意图，其余配图由平台匹配或生成。
- 智能演示：只提供一份 PPT 大纲，不预先提供完整配图。
- 互动影片：默认只填写创意，不带入既有成片或全部节点素材。另备可选策划脚本，用于演示已有脚本的路径。

首页预设需求同步更新；已有 v1 资料原样保留。所有企业名称、事件与指标为虚构演示，生成配图不作为真实历史照片。

## 验证

- `tests/demo-inputs-v2.test.ts`：最小输入边界。
- `tests/catalog-components.test.ts`：目录迁移、保留编辑与删除状态、真实 ZIP 检查与参数配置。
- `tests/e2e/catalog-components-v17.spec.ts`：社区预览、试编辑副本、插入画布与无附件故事预设。
- `scripts/check-catalog-components.mjs`：从实际组件截图，并检查年份切换、详情开关与 375px 窄屏，并在 `file://` 离线环境检查图片与交互。

本轮验证：目录测试覆盖率 100%，两项浏览器流程通过；离线检查报告位于 `output/catalog-components/runtime-check.json`。

联网图片仅在用户主动填写外部图片地址时使用。模型生成依赖平台服务；目录中两款组件自身可独立运行。来源署名与许可条件随源码保留，商业分发前应核对上游条件。
