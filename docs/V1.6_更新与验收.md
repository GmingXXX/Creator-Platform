# 智创平台 V1.6 更新与验收

日期：2026-11-12

## 本轮更新

| 范围 | 完成内容 |
|---|---|
| 命名与筛选 | 用户界面统一使用“设计风格”；项目、社区共用项目类型与展示内容/形式下拉筛选 |
| 交互程序创建 | 展示内容、展示形式默认“无”；创建不强制分类，投稿至少填写一项 |
| 创建入口 | 首页选择演示与视频、互动影片直接打开创建窗口；已有项目从项目列表直接进入编辑器 |
| 互动影片 | 流程、脚本、素材均可不填，进入零节点空白画布；也可生成节点草稿后确认内容、去向和素材 |
| 影片资料 | 支持脚本上传、节点素材批量上传与图片/视频/HTML 绑定；预设与自定义分辨率；封面引用随作品保存与复用 |
| 演示与视频 | 类型、设计风格、尺寸、页数/时长设置；生成大纲或分镜并编辑讲稿和顺序 |
| 画布 | 去除顶部类型标签；单选按画布、多选按选择范围对齐，锁定组件不参与修改 |
| 画布 AI | 空白与模板工程均可使用 DeepSeek 修改内容、样式、位置及添加已适配组件；支持范围限制、撤销与过期结果检查 |
| 生图 | 万相候选图预览后明确应用到背景或图片组件，保留前景；任务查询与重试沿用原任务标识 |

## 能力边界

- 本轮模型链路自动化使用模拟供应商响应，验证请求、结果应用、错误恢复与撤销；没有新增付费模型调用，不将模拟结果作为线上生成质量的证据。
- 已适配原生组件可生成配置并编辑；任意新组件代码自动适配不在本轮范围内。
- TXT、Markdown、DOCX、PPTX 可提取有限文字。PDF、旧版 DOC/PPT 保存为参考资料，界面提示未解析；未接入图片或视频内容理解。
- 演示与视频仍保存可编辑页面、讲稿和分镜工程，未新增真实视频渲染或 PPTX 输出。
- HTML 节点隔离运行；复杂外部依赖仍需适配。视频没有 poster 时使用已有占位预览，本轮未增加视频截帧。
- 多人共创仍为本地权限与资源归属演示，未新增服务端多人同步。

## 刷新入口补充

浏览器刷新后统一回首页，未登录用户先进入登录页。已有项目、素材及未发送草稿保留；正常站内导航与首次打开深链接仍可进入对应页面。实现位于应用启动阶段，未重置任何作品数据。新增刷新与登录检查 2 项、相关持久化回归 72 项全部通过；生产构建通过（index-B1tvipLn.js）。
