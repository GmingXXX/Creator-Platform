# 组件真实生成演示

## 本轮能力

本轮采用“真实模型编排内容和配置 + 已适配组件装配”的方式，生成企业成果悬浮卡片组。模型使用用户需求、选中的设计风格、Skill 与已解析的参考文本，返回经过校验的标题、简介、成果卡片和样式。平台将其装配为可独立运行、可上传试编辑的 HTML 资源 ZIP。

支持鼠标悬浮倾斜和光晕、点击详情、键盘访问、触屏浏览、窄屏重排和减少动态偏好。当前六项开放参数为主标题、简介、成果卡片内容、主题色、桌面列数、悬浮强度。

没有原始数值的卡片应留空数值，不凭空填写。事实仍由用户在检查与试编辑阶段核对。

本轮不宣称能够把任意源码自动适配成原生画布组件，也不自动安装未知第三方依赖。

## 输入示例

> 根据上传的星澜智造企业资料，制作一个用于企业展厅的成果悬浮卡片组，展示智慧产线、研发平台和服务网络。使用科技风，保留“模拟演示数据”的说明。点击每张卡片能够查看成果详情，支持修改卡片内容、主题色与悬浮强度。不要编造资料里没有的经营数据。

## 组件包

- `component.json`：编辑协议和六项默认参数。
- `index.html`、`cards.css`、`cards.js`：独立运行所需资源，无外部库和网络资源依赖。
- `generation.json`：生成时的模型、提示词、设计风格、Skill、参考文本、模型计划和最终参数。
- `README.md`：运行、导入和能力边界。

检查阶段下载的是初始组件包；保存后素材的“下载组件包”使用最终试编辑值。下载的 ZIP 再次走普通组件上传时能读取这些默认值。

保存时 HTML 运行副本与完整 ZIP 存入浏览器文件存储。素材库只增加一个组件资产，ZIP 保存在其创作资料包中，不额外污染普通文件列表。

## 接入接口

`generateComponentPackage(input, signal)` 返回 `{file, plan, inspection}`。

`GeneratedComponentReview` 接收 `{input, workspaceId, open?, onClose, onCreated}`，执行需求确认、真实生成、检查、预览试编辑、保存和回调。

`GeneratedComponentPackageDownload` 接收 `{asset}`，仅在生成 HTML 资产关联 ZIP 时显示下载按钮。
