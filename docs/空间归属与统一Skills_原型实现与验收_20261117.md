# 空间归属与统一 Skills：原型实现与验收

依据：[空间归属、创作参考与 Skill 元信息调整方案](空间归属、创作参考与Skill元信息_调整方案_20261117.md)。本轮已在本地原型落实。

## 1. 如何体验

| 场景 | 操作路径 | 实际结果 |
| --- | --- | --- |
| 移动个人作品 | 个人空间 → 项目卡片菜单 → 移动到项目空间 | 选择目标并查看随迁内容，确认后进入目标空间；保持作品身份，复制实际依赖素材 |
| 项目使用个人素材 | 素材选择器 → 从个人空间带入 → 带入项目并使用 | 生成项目独立素材记录，个人原件保留；嵌套依赖一起采用并改写引用 |
| 刷新继续工作 | 在项目首页输入需求、添加附件和参考后刷新 | 保留当前空间并恢复对应草稿；作品和任务深链接刷新保持原入口及所属空间 |
| 多维度参考 | 首页或作品 Agent 输入框底部 → 创作参考 | 可多选交互、UI、内容组织、局部效果；支持全部与半选；来源范围独立选择 |
| 查看或新建 Skill | 侧栏 Skills → 可用技能 / 新建技能 | 统一目录随账号权限展示，通用个人方法跨项目使用 |
| 从经验沉淀 Skill | Agent → 整理制作经验 → 提炼为 Skill | 自动预填候选定义，检查完整元信息后保存私有、未启用草稿 |
| 编辑与导出方法 | 技能详情 → 编辑技能信息 / 导出当前技能包 | 新建、编辑、经验提炼使用同一表单；导出当前定义和附带资源 |

创作资料入口仍保留在素材卡片详情中，没有新增作品或模板资料页签。

## 2. 空间移动和上下文归属

移动对象是个人作品及与其关联的制作上下文。随迁包括当前工程、相关生成任务、对话、撤销快照、经验、创作资料包和参考记录。未发送个人草稿不迁移；已提交任务的需求和附件保存在任务记录中。

工程相关素材按依赖树复制到项目：页面背景、封面、节点、条目、故事媒体、分镜、生成方案配图、包内 JSON 和关联文件都保持有效引用。原有个人素材及无关作品不被移走。已有同版本采用记录可复用。

正在运行的任务、待返回的背景生成及可恢复的后台生成失败，会阻止移动。移动发生后，旧空间编辑快照不能回写；迟到的模型或背景结果不能写入错误空间。

私人来源展项只随迁必要的结构快照和来源证据，不开放原作品。参考候选、实际采用历史与内部校验快照分别保存；移动不会把候选伪装成已采用。复制移动后的作品时，新副本独立保存引用快照。

Agent 请求以任务或作品所属空间为准，携带该项目名称、说明，以及本次相关工程、对话、附件、参考与可用方法。切换当前浏览空间不改变后台任务的归属。项目自动素材候选不再包含个人私有素材全集。

## 3. 刷新规则

- 首页刷新保留当前空间，以及该空间的需求、附件和参考。
- 旧活动草稿属于其他空间时，不再反向改变当前空间。
- 目标空间没有草稿时创建该空间的空白草稿，不挪用其他空间的输入。
- 首次进入默认个人空间；原空间不可用或保存身份失去访问资格时，提示原因并回到个人空间。
- 作品、任务和制作工具的深链接刷新保留入口；未登录仍需登录，登录后恢复原目标。

## 4. 创作参考

底部按钮用于添加和管理参考；无参考时不显示上方大块空面板。已有参考按来源显示紧凑摘要，内部仍逐维度记录版本、范围及采用结果。

“全部”表示四种参考维度，不代表复制原客户事实、媒体和完整工程。多个候选、局部范围和补充要求继续遵循原有冲突及采用记录规则。

## 5. 统一 Skills 和元信息

统一目录不再分“我的技能 / 项目共享”两套使用入口。个人方法可跨项目使用，旧项目方法保留原有成员访问范围，私有草稿不会因为目录合并而自动开放。作品固定采用的方法版本快照，不再复制一份项目 Skill；后续编辑方法不会改写既有作品。

新建、编辑和经验提炼统一支持：

- 基本元信息：名称、唯一标识、描述、版本、作者、分类、标签、图标。
- 用途与执行约定：用途、适用场景、不适用条件、输入、步骤、输出、检查标准。
- 依赖与权限：工具或服务、数据资源、读写操作、授权要求。
- 示例与验证：示例、验证状态、已知限制、来源经验版本。
- 管理信息：维护者、可见范围、启停状态。

标识自动生成且只读，作者和版本有默认值；Agent 提炼内容作为可编辑候选。权限声明不等于已获授权，也不自动连接外部工具。

投稿 Skill 时清除内部出处和账户管理信息，公共导出重新构建经过净化的技能包。投稿展项或素材也不会连带公开私有 Skill 定义、私有制作经验或内部参考。

## 6. 验证结果

- 生产构建和 TypeScript 检查通过。
- 88 个单元/集成测试文件、900 项测试全部通过。
- 按仓库配置统计：行/语句覆盖率 98.70%，函数 98.82%，分支 90.87%，超过 80% 门槛。
- 最终核心浏览器回归覆盖 22 项场景，均已通过分批复验：刷新、登录深链接、移动后续作、素材显式带入、底部参考多选、经验提炼、Skill 元信息和已有编辑对话。
- 另完成素材专项 7 项和 Skills 专项 5 项浏览器验证，与核心回归存在重叠。
- 评审发现的后台背景生成迁移、候选历史误标、配图 ID 漏迁、私有 Skill 随工程公开、跨账号采用状态问题均已修复并回归。

所有模型请求使用模拟响应或本地演示规则，没有进行真实付费模型调用。当前仍是浏览器本地原型，ACP 知识检索、真实多人服务端权限和真实模型输出质量不在本轮已验证能力中。构建仍有既有的大文件打包提示。

## 7. 2026-11-18：作品命名与空间生命周期

- 创作对象统一称为“作品”，覆盖导航、创建、列表、编辑、预览及相关提示；“项目空间”继续表示协作容器，客户案例中的业务“项目”名称保留。
- 空间切换器增加搜索、可滚动列表和固定管理入口。管理界面分为使用中、已归档、回收站。
- 项目空间负责人可以归档、恢复、移入回收站；个人空间不可归档或删除。归档后只读预览，日常切换列表隐藏；删除当前空间自动返回个人空间。
- 回收站支持恢复。彻底删除前展示影响数量并要求输入空间名称，清除对应本地内容记录、成员设置与智创侧 ACP 绑定；不删除外部 ACP 知识资料、不影响其他空间或已发布社区副本。存在未隔离的跨空间私有依赖时阻止彻底删除。
- Skill 按实际权限元数据判断归属，个人或团队 Skill 不因历史来源空间删除而被误删。预设空间的删除状态持久保存，刷新不重新填充。
- 修复从旧任务切换空间时被路由同步拉回的问题；已删除空间的私有投稿和直接链接不再可访问。

本轮验证：生产构建通过；92 个单元/集成测试文件、928 项测试通过；18 项浏览器场景通过。新增生命周期与投稿访问检查模块行覆盖率 100%、分支覆盖率 87.59%（仅这两个模块的专项统计）。已检查 1440×960 和 1024×768 管理弹窗布局。

测试使用隔离浏览器数据与模拟模型响应，未操作真实用户空间。仍为浏览器本地原型，不能替代服务端多人权限校验；彻底删除清理本地业务记录，不表示安全擦除共享文件存储。ACP 服务端资料未执行删除。

## 8. 2026-11-18：统一空间设置入口

空间下拉仅保留切换、新建和管理入口。进入“管理空间”后，可在列表对任意有权限的空间点击“管理”，无需改变当前创作空间。详情包含三个页签：

- 基本信息：修改名称与说明，名称校验及防重；归档和移入回收站集中在下方。列表的生命周期操作收进“更多”菜单。
- 成员与权限：邀请、模拟接受、撤销、权限修改、移除及负责人转让。转让需要确认，只能交给已加入成员，原负责人降为编辑者；持久化保留唯一负责人，移除旧负责人后刷新不会重新加入。
- 知识本地场：查看、保存、更换与解除本地 ACP 绑定，保留已有文件的历史归属记录。对话框知识本地场按钮直达这里；创建空间后的邀请按钮也直达这里。

个人空间不开放协作设置和生命周期操作；归档空间设置只读。非负责人不能修改名称、成员权限或绑定。成员邀请仍为本地模拟，ACP 服务尚未连接。

本轮构建通过，93 个测试文件、936 项单元/集成测试通过；负责人转让与基础设置域模块专项行覆盖 100%、分支 92.03%。浏览器验证覆盖统一管理、非当前空间改名、归档只读、个人空间保护、邀请与转让持久化，以及原有权限和 ACP 上传归属流程。已检查桌面与 1024×768 成员页布局。
