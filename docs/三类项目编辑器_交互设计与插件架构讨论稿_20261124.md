## 1　交互界面编辑器

**现状核查。** 当前组件库按三个一级组直接铺单个类型，素材栏已有「当前空间／共创社区」、搜索及拖入替换。图层已有前后半行的拖放判断，但列表底部空白没有接收区，可解释用户所遇到的最底层难以投放，尚未在用户设备复现。属性区标题的箭头没有点击处理，名称和坐标排在内容前。画布双击空媒体框可以添加素材，已有素材或文字的双击主要是展开右栏。交互规则的「当」固定给出点击和视频开始，每条只有一个动作目标。新增语音口令取组件首条交互的动作，无交互时默认为打开详情。这些已有入口可延用，后续重点改操作结果。[组件与图层](../src/features/editor/EditorPage.tsx#L156) · [素材栏](../src/features/editor/EditorMaterialsPanel.tsx#L8) · [属性、交互与命令](../src/features/editor/Inspector.tsx#L15)

### 1.2–1.4　找素材、理图层、改内容

- **素材。** 先选「当前空间／共创社区」，在两个来源相同位置显示「全部、图片、视频、音频、可编辑组件、交互程序」类型筛选，窄栏用单行类型选择器。关键词、来源、类型共同生效，切换来源保留类型。替换视频时直接进入视频结果，显示「上传视频」；空结果给出清除条件或切换来源。素材能否使用继续按空间权限判断。
- **图层。** 顶部代表最前，末行下方留常驻可命中的放置区；拖近底边自动滚动，蓝线预告最终层级。最右侧固定删除，锁定时禁用，支持撤销。双击图层名改名，Enter 保存，Esc 取消。文本默认取首行非空内容作为名称，清空时显示「文本」；用户手动命名后保持自定义名。其他绑定使用稳定标识，改名、调整层级后保持有效。键盘或右键仍可置顶、置底，无需精确拖动。
- **属性。** 单击选对象，双击编辑内容，预览模式再执行访客交互。文字原位输入并用就近工具条改格式；双击图片、视频、音频打开相应素材选择器，支持本地上传或从空间替换，保留位置、裁切方式和交互。双击复合组件具体条目编辑该项，双击其容器可批量整理。右栏分组标题整行支持点击及键盘折叠，保留当前编辑上下文；「精确布局」默认折起，提供位置、大小和角度。无需重复展示组件名称输入框。

| 对象 | 右侧优先显示 | 次级选项 |
|---|---|---|
| 文本 | 内容、字体、字号、颜色、字重 | 对齐、行距、字距 |
| 图片 | 当前素材、替换／裁切、适配方式、不透明度 | 边框、圆角、蒙版 |
| 视频／音频 | 素材、播放试听、音量、自动／循环播放 | 视频封面、适配、控件显隐 |
| 鱼骨时间轴等复合组件 | 年份、条目标题、描述与配图，可排序、新增、删除 | 分支方向、条目样式与间距 |
| AI 语音控件／装饰组件 | 分别显示形象与各状态预览，或图形／图标的填充和描边 | 尺寸、透明度等适用选项 |

无选中对象时显示页面背景和页面布局；多选只列共有属性并提供对齐、分布。锁定对象允许查看和解锁。屏幕触控或无法双击时，选中后的「编辑文字／替换素材／编辑条目」是同一操作的另一入口。

### 1.5　把交互写成一句可测试的话

建议界面使用 **「当……，如果……，就……」**。日常所说的「点击」和「视频播完」都可以成为「当」中的触发时刻。「如果」检查触发时的状态，「就」才是平台执行的动作。因此「视频开始播放」和「播放视频」应分别出现在触发列表和执行列表。快捷配置只露出「当／就」，需要额外限制时点「添加条件」。Adobe XD 也区分触发、动作与目标，并允许一个触发组合动作；这里的跨卡片进度及展厅空闲规则是为本项目设计。[Adobe XD 官方交互说明](https://helpx.adobe.com/xd/desktop/prototype/create-prototypes.html)

| 用户意图 | 在哪里配、何时触发 | 执行结果 |
|---|---|---|
| 点图看详情，或点击自身改变状态 | 图片／按钮 → 访客点击 | 打开该图详情；也可以把目标选为「自己」，切换选中样式 |
| 视频播放时隐藏提示并点亮说明，结束时翻页 | 视频 → 开始播放；另建「播放结束」 | 第一条添加两个动作，各指向本页不同组件；第二条跳到指定页面 |
| 一分钟无操作回首页 | 页面空白 → 交互 →「连续无操作」60 秒，可应用到多个页面 | 返回首页。访客点击、触摸、键盘或有效语音重置计时；媒体自动播放不算访客输入，可勾选「讲解播放时暂停计时」 |
| 看完所有卡片进下一页 | 页面 →「指定卡片已全部点开」，在画布勾选目标卡片 | 按不同卡片累计，重复点同一张只算一次，完成时执行一次翻页。默认重新进入该页重新计算，可选保留本次参观进度 |

触发来源分成「访客操作、组件状态、页面与进度」，按所选对象只给出适用项。文本／图片可点击，视频另有开始、暂停、结束；页面空白仍能配进入、空闲及进度规则。选中组件时展示「此组件」并提供「本页规则」入口。动作选项依目标能力过滤，页面可跳转、媒体可播放、组件可显隐。支持同一动作作用于多个目标，也可添加不同动作，按可见顺序发起；需要等视频播完才能做下一步时，用播放结束触发后续规则。跳转放最后；目标已删除、同一目标同时显示和隐藏、无条件自触发循环均应在保存或预览前指出具体规则。预览提供「模拟空闲 60 秒」、已访问卡片计数及最近触发记录，退出后恢复编辑态。



用卡片案例比较两种配置就容易理解“事件”和“条件”。如果观众**点开最后一张未读卡时就翻页**，选“卡片已全部点开”作为触发。如果希望观众**看完后自己点‘继续’才翻页**，选“点击继续”作为触发，再加“所有卡片已点开”作为条件；未满足时可显示还剩几张。两种体验只差一个时机，作者可以在预览里直接试出区别。

### 1.6 动效：先看见效果，需要精调时再打开时间轴

**客户入口。** 选中「欧几里得视频」，打开右侧「动效」，首屏展示一句可读的配置「视频开始播放时，让整个页面向视频靠近」。下方依次是带实际页面缩略图的可重播预览、效果、时长，以及「精调时间轴」。用户只想换效果时，打开有分类、搜索和悬停／点击预览的选择器，选完立刻看到当前内容的效果。高级选项提供延迟、速度变化、播放结束后停在哪里。选中已有跳转或打开弹窗的规则时，可从「交互」点「添加转场」直接到同一份配置。普通用户能理解「一起播放」「等上一项完成」等时间关系，这一表达也与 PowerPoint 的动效设置接近。[Microsoft 动效与顺序](https://support.microsoft.com/en-us/powerpoint/training/animate-text-or-objects)

| 演示任务 | 实际操作和可观察结果 |
|---|---|
| ① 卡片跳页、文字开窗、卡片展开 | 从已有规则进入，自动带出来源、目标及触发时机。给跳页选淡入，给弹窗选轻弹；卡片本身展开时可叠加轻弹。删除附加效果，再试一次，原有操作仍成功。可将效果安排为「先播效果，再执行」「同时开始」「动作完成后再播」，从顺序列表拖动调整。永久离开原页面的动作应只提供能看得到的时机与目标。 |
| ② 点击静态文字，让另一对象变化 | 新增效果时默认「点击这段文字」，默认作用于自身。点「谁发生变化」可从项目页、容器、组件中选择，也可连续添加多个。演示点击文字，同时让照片出现、标题上移；换照片时顶部的触发说明保持原样。容器一起移动时子内容跟随。 |

| ⑥ 看懂与调整每个标记 | 属性旁标记同时给图形与文字提示「未记录／其他时刻已记录／此刻已记录」，点实心标记可移除此点。可设整段或至下一帧的变化速度，如匀速、渐快、渐慢、两端慢、中间快或保持当前值。序列结束可选停在最后画面或回到本次触发前的状态。 |
| ⑦ 视频播放时推进，结束时复位 | 用 10 秒示例，视频真正开始播放后，给整页录下 0 秒全景、2 秒推近、8 秒维持、10 秒全景，视频组件保持自身尺寸。默认片段等于实际视频长度，视频暂停／继续带动镜头，从当前位置接着播。手动延至 12 秒时保留所设长度，视频结束后再播完剩余两秒。拖预览进度只定位。可用「播放这段」检查序列，也可用顶栏「预览」依次试点击、跳页、开窗、播放；退出回到原始编辑布局。 |
| ⑧ 保存与再次编辑 | 在原型内应用修改、重新选择触发对象，能够找回多对象片段、开始时刻、持续时间、属性点、缓动和结束方式。走完一次保存、重开和恢复已保存版本。可用示例视频、截图及本地存储完成演示，正式接入的对象、组件事件和项目保存另行验证。 |

同目录另一份需求短稿把页面转场列为后续开发，并提出动效对外发事件以备后用。V5.1 已明确给出页面跳转、弹窗和接缝转场。建议本轮原型完整演示 V5.1，并让用户比较「动作前／同时／动作后」。页面切换可用两张页面快照演示，正式双页面同时渲染、外发动效事件的实现留作工程评估。这样一次客户评审就能判断「是否易配、是否看得懂、这个画面是否符合预期」。[同目录需求短稿](/Users/ming/Desktop/unidt/project/智能化展厅通用产品/动效模块原型/动效系统功能需求描述.md)

### 1.7　让口令直接对应组件会做的事

右栏建议命名「语音指令」。组件入库时登记其支持的动作和默认说法；编辑实例时每行显示「动作｜默认说法｜我的说法｜启用」。视频明确区分播放或继续、暂停并保留进度、停止并回到开头、从头重新播放，分别可试。图片可打开详情，弹窗可打开或关闭，静态装饰只列其实际支持且需要暴露的动作。自定义说法可追加多个别名、关闭默认说法或恢复默认，并明确选择绑定动作。

例如在「祖冲之」视频的「从头播放」一行添加「请祖冲之讲一讲圆周率」，用输入框模拟听到这句话，展示“匹配到祖冲之视频 → 从头播放”，预览里实际执行。默认范围为本页；作品级口令可用于返回首页等全局行为。多个视频都支持「播放视频」时，优先明确对象或当前活动视频，仍有多个候选就提示选择或补充对象名。编辑时对重叠范围的重复说法给出目标和修正入口。演示应标明文字模拟与真实拾音的区别，生成默认指令、改别名、冲突和执行均可验。

## 2　智能演示

**现状核对。** 独立新建入口会拒绝空主题，默认 8 页，页数输入、大纲校验和草稿恢复都有 30 页上限。当前 PPTX 读取路径抽取幻灯片 XML 正文，未在该路径解析页面、母版与内嵌图片的对应关系。大纲中已经可以逐页改标题、正文、讲稿和配图，但同时露出版式和配图描述。编辑器已有画布移位缩放、上下移页、删除、复制、逐句停顿、标注和时间轴，可直接沿用这些能力。以下是建议设计，依据当前源码静态核查。[创建流程](../src/features/studios/PresentationCreationDialog.tsx) · [生成校验](../src/domain/presentation-generation.ts) · [文档解析](../src/domain/document-intake.ts) · [编辑器](../src/features/studios/PresentationEditor.tsx) · [编排面板](../src/features/studios/PresentationPanels.tsx)

**2.1　上传资料后自动起题。** 打开新建即可上传。资料解析后在可编辑的主题框自动填入一句建议，旁边显示“来自《…》第 1、3 页”。用户手动输入过主题时，把新建议放在旁边，点“采用”才覆盖。多份资料主线冲突时给两个有依据的主题供选择。无可解析内容时提示实际原因，允许手填主题继续。页数默认“由 Agent 决定”，并列“约 5／8／15／25／40 页”，选中后可微调到具体页数。“约”允许推荐合理增减，生成前显示实际大纲页数和差异原因。40 页需要同步更新生成、草稿恢复和离线演示，不宜只扩大输入框。大纲前按资料篇幅、拟定页数和内容密度给预计时长区间；有讲稿后按各页实际字数、语速、停顿、媒体等待累计，配音就绪后以实测音频更新。页数相同的图集和技术讲解应给出不同估时。参考 Microsoft 将引用文件用于起草并允许编辑的流程。[Copilot 从文件起草幻灯片](https://support.microsoft.com/en-us/powerpoint/copilot/add-a-slide-from-a-file-with-copilot-in-powerpoint)

**2.2　确认大纲与素材。** 步骤统一为“主题与资料 → 确认大纲与素材 → 开始生成”。左侧显示可折叠的页码与标题导航，选中某页后右侧按阅读顺序只呈现主标题、副标题、正文、配图、讲解词。副标题可空，讲解词可独立展开。图片位置直接显示缩略图与“替换／AI 生成”；在“AI 生成配图”弹窗才出现配图描述、参考图和生成结果。点击“开始生成”出现实际进度、失败页和重试入口，保留已确认内容。**截图一**对应大纲顶端的“让 AI 改写”输入框，提供“更精简”“增加案例”“突出数据”“调整叙事顺序”快捷项。明确本页或整份范围，预览改动的页、字段和页序，再应用或放弃；支持撤销。涉及新增案例或数据而资料没有依据时，留下“待补资料”，保留手工锁定的事实与已选图。

导入 PPTX 时要同时保留“哪一页的哪个位置使用哪幅图”和“它在这个位置的用途”。结合页面或母版来源、重复位置、裁剪面积、邻近说明、图像内容推定为正文配图、品牌标识、图标／标记或背景装饰。同一图片在不同页可有不同用途。普通图片随内容进入配图槽，Logo 锁比例并进入品牌位，功能图标邻接相应文字，背景留在背景层。识别不确定时在“核对导入素材”展示原页缩略图、框选位置、候选用途，可逐项更正或批量改同一标识。整页扁平图只作为整页候选，避免承诺可以无损拆出 Logo。原型可用一份含重复 Logo、主图和小图标的样稿演示判断、纠错及排版结果，通用识别能力需另测。旧版 .ppt 按实际解析能力提示转换为 .pptx。

**2.3　缩略图按熟悉的方式操作。** 两个制作模式共用一套页栏。拖动时显示上下插入线，末页之后也可放下。缩略图获得焦点时 Delete 删除，Ctrl/Cmd+C、V 复制并在当前页后粘贴；提供菜单同等入口和撤销。正在打字时这些按键作用于文字，选中画布元素时作用于元素。新增页插在当前页后，继承当前项目主题、尺寸、字体与品牌位，可选择同主题版式。复制页要连同讲稿、标注、动效和热点一起复制，并将内部引用指向新元素；调整页序后音频和标注仍跟随原页。[WPS 的页复制与粘贴位置](https://www.wps.cn/learning/room/d/328222) · [PowerPoint 页面操作](https://support.microsoft.com/en-gb/powerpoint/training/add-rearrange-duplicate-and-delete-slides-in-powerpoint)

**2.4–2.5　在画面上改内容，右栏随选择变化。** 双击文字出现原位光标，选中文字出现字体、字号、字重、颜色与对齐；双击图片或视频打开替换，保留外框，替换后可调裁切。多选可对齐、等距分布。右侧统一为“属性”。点页面空白显示本页版式缩略图与背景，点文字、图片或视频显示同交互页面一致的专属属性。需要精调时展开“位置与尺寸”。快速换版式先预览，如从“左图右文”切成“上图下文”，按主标题、副标题、正文、配图槽位重新排布，保留讲稿及元素标注；自由摆放且无法对应的内容保留，并提示检查位置。右上 Agent 旁的“设计风格”显示当前主题，预览后应用整份。单页换版式与整份换风格分别在各自作用范围内操作。[WPS 的版式与占位符](https://www.wps.cn/learning/room/d/229463) · [PowerPoint 的主题、版式与占位符](https://support.microsoft.com/en-us/powerpoint/training/apply-a-slide-layout)

**2.6　讲解编排。** 切换后保留当前页、同一列缩略图和底部时间轴，右侧提供三项。①“讲稿”按句编辑，设置句后停顿，选择文字或图示作为高亮、划线或圈注对象，点句子试听并在画面中看到标注。页面制作下方的整段讲稿和这里的分句应共用一份内容，改句后仅标出受影响的配音和标注。②“语音配置”提供音色、语速、语调、短句试听，同时说明设置作用于整份或本页。克隆声音可走授权样本、处理状态、试听、选用的演示流程；当前实现只保存已授权样本，已接入音色与示例克隆结果要清楚标识。[当前语音配置](../src/features/studios/PresentationVoiceSettings.tsx) ③“动效”默认展示本页转场与页内演示预设，缩略预览直接使用当前页内容；转场用上一页和本页相邻画面，支持重播、时长、应用到同类页，并可与讲稿同播核对。页面只要调整需播放才能判断的动效，都就地提供小预览。

**2.7　消除重复入口。** 截图二中“本页讲稿”的文字框保留，删除其下“进入讲解编排”按钮。由左上“页面制作／讲解编排／互动问答”统一切换，同页和编辑位置随切换保留。

**走查场景。** 上传含正文配图、重复 Logo 和装饰图标的 PPTX，让 Agent 填主题，选约 40 页并微调，核对大纲图像用途；对一页要求“更精简”并撤销，开始生成。把第 2 页拖至末尾，复制一页并核对讲稿标注，双击替换图片，切换本页版式与整份风格。进入讲解编排，调整一句停顿和一处标注，试听并观察预估时长变化，最后在小窗比较两个转场。

## 3　互动影片：先看故事怎么走，再编辑每一幕

当前创建流程已经支持上传图片、视频和单个 HTML，逐节点填写文案和分支。确认页仍以卡片列表呈现，节点详情只有一份场景素材和选项表单。自由画布已支持拖动节点、连线、双击详情及 Delete 删除，左侧节点库靠点击添加，右侧固定，小地图常驻。现有四类是开始、故事场景、分支选择、故事结局。预览 HTML 能收到体验完成通知，尚需把它接入下面建议的事件与跳转。这些是源码核查结果。[确认页](../src/features/studios/StoryCreationDialog.tsx) · [流程画布](../src/features/studios/StoryEditor.tsx) · [节点详情](../src/features/studios/StoryNodeDetails.tsx) · [HTML 预览](../src/features/studios/StoryHtml.tsx)

**3.1　确认节点与素材。** 默认从左至右按故事层级排布。卡面展示节点类型、名称、主画面缩略图与素材状态，连线上写观众看到的选项或自动跳转的原因。点击卡片后在侧栏核对内容和素材，允许批量上传、分配已有素材、替换和预览。节点可以使用纯视频、图片或视频叠加 HTML 按钮、完整 HTML 体验。素材按“背景画面、互动控件、完整互动内容”显示其用途。两条路径汇合到同一结局时只画一张结局卡，回访已有场景时显示带名称的回线。缩小后可读故事结构，放大可核对每幕素材。

**3.2　四种节点。** 开始节点是唯一入口，可直接显示内容并分支。普通节点可叙事、播放媒体或提问。拍照节点预置相机区域、拍摄、重拍、确认，支持以“照片已确认”或“选择跳过”进入不同后续节点。结束节点可呈现结局画面，无后续分支；“再体验一次”从入口重新开始。前三类均可从卡片加分支。旧“场景”“分支选择”统一映射为普通节点，保留已有按钮、条件、坐标和连接。旧互动内容需经作者确认才切为拍照节点。切换为结束节点时如已有出线，先列出受影响的分支并允许取消。

**3.3、3.4、3.8　画布布局。** 流程总览取消固定左栏。画布顶部中心放四种带文字的节点工具，拖到指定位置即可创建，点击也可在视口中心添加；已有开始节点时，点击“开始”定位到入口。单击卡片打开可折叠的右侧属性栏，双击进入节点内容编辑，空白画布保留最大可视面积。折叠后留下可用键盘操作的展开按钮。小地图默认关闭，在缩放工具旁以“导航图”打开；“适应全图”一步找回全局。节点内部编辑仍保留可折叠左右栏，服务于素材和属性编辑。Dify 提供无限画布、连接和分支的参考，以上工具条位置和节点语义是针对展项的设计建议。[Dify Workflow](https://www.dify.ai/blog/dify-ai-workflow) · [Dify Workflow Studio](https://www.dify.ai/workflows)

**3.5　连线。** 从一个分支出口拖到目标节点建立连接；再拖已连接的目标端，落在另一个有效入口时改接，落在空白处时提示“松开以断开”，释放后保留分支名称与触发规则，目标显示“待连接”。Esc 或落在无效节点时还原。选中线也可以用 Delete 断开，撤销一次恢复原连接。仅在发布或沿问题路径试运行时指出缺失目标，允许临时断开的草稿保存。这里要区分“断开去向”与“删除整个分支”。[React Flow 改接连线](https://reactflow.dev/examples/edges/reconnect-edge) · [空白处松开断线](https://reactflow.dev/examples/edges/delete-edge-on-drop)

**3.6　节点快速属性。** 上半部为名称、类型、简介，下半部为“发生什么时，接下来做什么”。截图三所示规则可以收成一句“当《转场.webm》播放完毕，进入「留真（拍照）」”。点击句中带下划线的对象、时机或目标即可替换；选视频才显示播放相关事件。常用模板包括“点选项后进入下一幕”“拍摄确认后显示照片”“互动体验完成后继续”。按需展开“仅在……时”和“再做一件事”，显示动作先后，并可排序。节点面板汇总本幕全部规则，节点内选中控件时只显示与它有关的规则；两处编辑同一条记录，分支线的标签和目标同步更新。一个触发可以显示多个组件，同次触发只允许命中一个立即跳转的目标；多个候选结局用互斥条件或明确的先后优先级表达。

**3.7　节点内容编辑。** 双击节点进入接近全屏、可最大化的独立编辑窗口，标题显示“影片名 / 节点名”。左侧共用“组件、素材、图层”，中间直接双击改字或换图、换视频，拖动调整位置，右侧按所选对象显示类型特有属性。控件共用图层命名、对齐分布和事件绑定。若一个视频画面叠加两个按钮，三个对象分别可选、分别可编辑；完整 HTML 默认整体替换、等比缩放和预览，只有素材声明开放的字段和事件才可逐项修改。拍照节点可用样片走通“拍摄→重拍→确认”，界面标注模拟，真机摄像头另验。顶部提供“预览本节点”“完成并返回流程”；返回后保留原画布缩放、位置和节点选中状态，未保存退出时可继续编辑或放弃草稿。

**演示用例。** 从开始节点分为“看影片”和“去拍照”，影片结束也可汇入同一拍照节点，确认照片后进入结局。现场将影片出线拖空、撤销、改接，再在节点窗口替换视频、移动按钮。检查右栏规则与连线一致，分别从两条路径试运行；折叠面板、关闭导航图后仍能找到对应入口。

## 4.1–4.4 三种编辑器共用的编辑方式

**4.1 Agent 的任务与选区。** 现在三个界面都能打开作品助手，代码已有作品、页面、节点三种目标，选区变化会改变默认目标。建议在输入框旁显示可改的作用范围。用户说“生成一段数学家讲解视频”时，即便正选中标题，也先在会话中交付素材卡，显示预览、保存到当前空间、插入当前页三个动作。未选页面也能生成图片、视频、组件，生成成功即可在发起任务的空间找到。用户说“替换这段视频”时，提交前显示将修改的页与对象。异步生成时固定任务归属和替换目标，切到另一页或另一空间不会误贴。目标被删时保留成果供手动插入，生成失败可重试。插入后可撤销。现有入口见 [FloatingWorkAgent.tsx](../src/features/editor/FloatingWorkAgent.tsx)。

**4.2 分辨率与适配。** 顶栏统一显示“画面尺寸 · 1920 × 1080”，提供横屏、竖屏、超宽和自定义。画布缩放只改变编辑视野，画面尺寸决定输出。同一比例优先保持相对几何；横竖互换时先生成适配预览，再让用户采用，整次可撤销。建议首版以整个项目为作用范围，沿用同一输出尺寸，预览列出受影响页，支持逐页修正。以展厅横屏改竖屏为例：

| 对象 | 推荐重排 | 需要人工决定的情况 |
|---|---|---|
| 图文、卡片、导航 | 双栏改纵向，卡片依阅读顺序重排，按钮锚定安全区 | 文字溢出或触控区过小时标出对象，可调整字号、分栏或内容 |
| 背景、视频、图片、热点 | 背景可铺满，视频默认完整显示；图片按焦点裁切，热点随同一张图的坐标映射 | 关键区域或热点将被裁掉时提供完整显示、重选焦点 |
| 智能演示 | 按新比例重选适合的本页版式，保留标题、正文、图片、讲稿及其关联 | 过长正文提供拆页建议，经确认再拆 |
| 影片节点及嵌入 HTML | 改节点播放画面尺寸，流程图保持作者排列；响应式 HTML 以实际视口预览 | 固定尺寸 HTML 默认等比留边，提供单节点预览并标记待检查 |

小比例调整可以由约束自动完成。跨度大的调整应让作者比较代表页，特别是竖屏视频与固定比例 HTML。可参考 Figma 对固定、随内容、填满容器的区分及 Adobe 的尺寸预设和自定义入口。[Figma 自动布局](https://help.figma.com/hc/en-us/articles/360040451373-Guide-to-auto-layout-in-Figma) · [Adobe Express 页面尺寸](https://helpx.adobe.com/sg/express/web/arrange-layers-and-pages/change-page-size.html)

**4.3 通用按钮与选区。** 左上统一为“返回、作品名、保存状态”，返回原来所在的空间或列表；右上固定相对顺序为“撤销／重做、画面尺寸、设计风格、Agent、预览”，导出、分享可收进相邻菜单，并按权限显示。保存失败要能重试，离开前可恢复或保存。演示的“页面制作／讲解编排／互动问答”留在模式栏，影片的“检查流程”留在流程画布工具栏。右栏分组标题可折叠，焦点与键盘操作遵循同一规则：

| 用户在做什么 | 三类编辑器的共同反馈 |
|---|---|
| 点画面空白 | 清除对象选中，右栏回到页面／节点画面的背景、排版。影片流程空白显示项目概览 |
| 点一个、多个对象 | 单选显示专有属性，多选显示共有项、对齐与分布。移动、缩放、旋转在画面中完成 |
| 双击内容 | 文本进入输入态，媒体进入替换，结构化组件进入条目编辑。Esc 逐层退出；输入时删除、粘贴、撤销归输入框 |
| 预览 | 从当前页或节点运行真实的预览交互，退出回到先前选区与缩放；动效面板另有局部试看 |

**4.4 制作阶段、设计风格与“查看作品”。** 当前演示、影片中的“查看作品”会先尝试保存修改，再回到相应分类的作品列表。因此编辑器内可以移除，保留“返回”和实际运行作品的“预览”。项目入口页的作品列表仍有独立导航用途。当前阶段切换还控制人工“交付检查”的显隐，建议移除“售前样稿／正式交付”模式，将仍有用的检查入口移到导出面板；历史检查记录随版本读取。见 [演示返回逻辑](../src/features/studios/PresentationEditor.tsx)、[影片返回逻辑](../src/features/studios/StoryEditor.tsx)、[当前交付检查](../src/features/creation/ProductionStageControl.tsx)。

设计风格是项目级规范，包含版式网格、间距、标题和正文字体层级、颜色角色、组件外观和动效节奏。项目选定后，新增页面、节点、组件和 Agent 生成物继承同一套规范。切换前用当前作品预览差异，默认更新继承项，保留用户明确设定的局部样式；提供“恢复跟随项目风格”。换本页版式只重排当前页。风格切换不能替换作者上传的图片、改变跳转目标、播放结束条件或讲解顺序。对交互绑定的效果只更新视觉表现，不改变触发时机。现在交互编辑器已有整项目套风格、演示有本页／全部页选项，宜统一此处的入口、作用范围和覆盖规则。

## 4.5 让 Agent 按需求调用三种展项创作插件

建议在 DeepSeek Harness 中为交互页面、智能演示、互动影片各实现一个创作插件。插件加载时向工具注册服务登记创作工具及其用途、参数和执行方法。用户从同一个对话入口描述观众体验，Agent 据此选择已开放的工具，传入需求、资料引用、当前空间、已有作品或风格约束。工具调用平台已有创作服务，返回可继续处理的方案、任务或作品。用户也可以显式指定形式。编辑器承担生成后的人工精修，平台设置承担可用范围管理。

| 用户描述的体验 | Agent 选择的插件 | 工具接力示例 |
|---|---|---|
| “让参观者点数学家头像，自己探索不同年代的成果” | 交互页面创作 | 整理人物与资料，形成时间轴和卡片方案；确认后生成可点击的页面 |
| “根据这份资料做五分钟讲解，到现场能自动播放” | 智能演示创作 | 生成逐页大纲与预计时长；确认后生成画面、讲稿和配音，返回可播放作品 |
| “让观众选一条探访路线，每条路线看到不同结局” | 互动影片创作 | 生成分支与节点素材方案；确认后生成节点、绑定跳转，返回可试玩影片 |

如果用户只说“做一个数学史展项”，三种形式都合理，Agent 先问“观众主要是自己点着看、跟随讲解看，还是通过选择改变故事走向？”形式明确后可直接调用对应工具起草。建议每个插件先开放“拟定方案、按已确认方案生成、修改已有作品”三个业务操作，按实际需要增加操作；长任务先返回任务标识，完成后返回作品标识和预览入口。工具结果应当可被 Agent 或下一次工具调用读取，以便用户在对话里继续修改。生图、视频和配音由插件共用，同一份数学家资料可以用于多种作品。以下为拟议的自研插件，接入情况需通过实际调用验证。

**上游实际提供什么。** DeepSeek Harness 基于 Cordis，把模型适配器、工具注册、会话日志和 Agent 循环都做成可以组合的插件。源码中的工具服务按作用域选择执行器，执行前可检查适用的限制。这适合借鉴为「当前用户、所在空间和所选项目决定 Agent 能用哪些工具」。官方将其标为开发者预览，提示兼容性可能变化，且尚未经过安全审计。因此建议先采用接口设计，如需引入实际运行时，再用固定版本独立验证。上述机制本身不能代替本平台的多租户鉴权。[官方架构](https://github.com/deepseek-ai/deepseek-harness/blob/master/docs/architecture.md) · [工具服务源码](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/core/tools/src/index.ts) · [版本状态](https://github.com/deepseek-ai/deepseek-harness) · [官方安全说明](https://github.com/deepseek-ai/deepseek-harness/blob/master/SAFETY.md)

| 归属 | 随该层提供的能力 | 客户看到的例子 |
|---|---|---|
| 平台公共服务 | 身份与空间权限、项目与素材保存、历史版本、任务状态、额度和服务端模型凭据 | 同一张生成图片可用于三种作品，跨空间使用须有相应权限 |
| 项目类型插件 | 登记项目类型、创建流程、编辑器入口、项目结构版本、专用操作、预览和交付方式 | 演示插件登记「生成大纲、调整页面、编排讲解」，影片插件登记「创建节点、编辑分支、试播路线」 |
| 共用创作能力 | 生图、生成视频、转写、配音、素材解析等，可供多个项目插件调用 | 页面或节点均未选中时仍可生图并保存至当前空间，之后可插入作品 |
| 创作技能与风格 | 技能说明如何组合已有能力，风格提供字体、颜色、排版和动效规则 | 「为讲稿配图」可使用已启用的生成能力；导入或收藏技能不授予新的平台权限 |

**接入现有原型。** 当前三个编辑器已有独立路由，管理中心已有账号、权限、共享资源和操作记录，管理员界面明确标注本机演示。服务端已有模型调用与图片任务恢复。可以先让插件清单指向原有入口并保持旧作品可打开，再让 Agent 和新建入口读取同一份可用能力清单。每个插件至少声明标识与版本、支持的作品版本、输入输出、需要的模型能力、访问范围以及前端入口。不要要求用户换用另一个客户端。[路由](../src/App.tsx) · [管理中心](../src/features/resources/AdminPage.tsx) · [模型适配](../server/providers.mjs) · [图片任务](../server/jobs.mjs)

**配置放在哪里。** 在「管理中心 → 平台配置」并列放「创作插件」「模型服务」，沿用已有「操作记录」。插件页显示用途、状态、版本、依赖、开放空间与受影响作品数；模型页按文本、图片、视频、语音分组，可测试连接、配置默认模型和使用限额。凭据交给服务端保存，界面仅显示配置状态和脱敏标识。空间设置只列平台已开放的能力，允许负责人决定本空间使用哪几项。创作者在编辑器只看到可用操作和服务不可用时的明确反馈。

| 角色 | 可操作范围 |
|---|---|
| 拥有对应配置权限的平台管理员 | 管理已审核插件版本、启停与回退、模型凭据、平台额度和可授权空间。管理插件权限和管理模型凭据可分别授权。平台管理身份沿用现有私有空间边界。 |
| 空间负责人 | 在平台授权范围内启用本空间需要的工具、选择允许的默认模型或风格、查看本空间用量。 |
| 编辑者 | 调用空间已启用的能力，选择当前任务允许的模型选项或风格，在有编辑权的作品中应用结果。 |
| 查看者 | 查看和预览获授权的现有成果。生成、插入、改配置均需对应权限。 |

**停用与升级也要能演示。** 例如停用配音前，显示受影响的空间、进行中的任务和依赖功能。停用后已有音轨仍可播放，生成新配音的入口提示联系负责人，已提交任务显示实际结算状态。停用整个项目类型时默认停止新建与新的生成调用，已有作品保留数据与固定版本预览；严重故障可退回最后的安全预览快照。作品格式升级在副本验证成功后再切换，保留原版本。若有未来的第三方插件需求，另设审核、版本锁定与隔离执行流程。

**实施顺序建议。** 第一阶段先从统一对话入口用三条不同需求分别调用三个插件，核对选型、输入资料、工具结果和作品预览，并验证模糊需求会先澄清。随后用内置插件清单和模拟配置走通「管理员为某空间启用影片 → 编辑者看到新建入口 → 创建作品 → 停用后旧作品可预览」以及「普通用户没有平台配置权限」。第二阶段从一条跨编辑器共用的生图链路验证服务端鉴权、配额、任务恢复与素材归属，再迁移三类专属编辑动作。第三阶段才决定是否引入 Harness 运行时，验证固定版本下的稳定性、授权、旧项目兼容、失败回退及升级成本。首轮演示可用状态模拟表现意图，生产可用性须通过实际服务端测试。

## 5　首页发送后进入统一创作会话，在对话中确定展项类型

目前首页发送逻辑会先判断是否需要澄清，命中后把问题卡插在首页输入框下方，确认后才启动任务并跳转。创作页左侧的作品对话框又依赖生成完成且已有特定作品。这解释了两张截图中的体验断点。[首页发送与澄清](../src/features/Composer.tsx) · [创作页对话与预览](../src/features/RunPage.tsx)

**首次发送即进入会话。** 首页负责写首条需求、上传附件、选择参考资料或风格。点击发送并成功保存首条消息后，立即打开该会话，保留首条消息、空间、附件与引用，不等待 Agent 完成分析。首页快捷示例若只填充草稿，继续留在首页；若触发发送，走同一路径。会话可以先于方案、生成任务和作品存在。返回首页后可从最近会话找回尚在澄清的讨论，刷新不会重复发送。

| 会话所处阶段 | 左侧对话与底部输入框 | 右侧工作区 |
|---|---|---|
| 首次发送，形式待判断 | 显示首条原话；可立即补充资料或要求。Agent 有关键歧义才提问 | 有资料就展示本次引用的文件或可核对的摘要；暂无内容时仅提示“方案将在这里呈现”。头部暂不显示展项类型 |
| 澄清与选型 | 问题和可点的快捷回答出现在消息流中，点击即作为用户回复；底部同一个输入框也可直接回答 | 得到足够信息后，展示推荐方案和选型理由。用户已明确形式时可直接看到相应方案 |
| 核对方案 | 用户可在底部要求改范围、换形式或补资料。需要确认的方案提供“开始生成” | 根据选定插件呈现交互页面结构、演示大纲或影片分支图，支持直接核对和编辑 |
| 正在生成、暂停或失败 | 输入框持续可见、可输入；生成中允许发送补充，明确提示将在本轮完成后处理；也可停止后按新要求继续 | 展示真实进度、已产生的内容及恢复入口，避免对尚未执行的步骤显示完成 |
| 已有结果 | 同一条会话继续改作品或另做素材，消息可以指向具体成果 | 显示可体验成果，通过“进入编辑器”精修，回到会话后保留当前预览 |

**屏幕布局。** 左栏由独立滚动的消息区和固定在栏底的输入区组成，长对话、长进度卡或打开右侧预览都不应挤走输入框。点选答案可直接发送，输入框为自由补充提供唯一入口。窄屏切换“对话／预览”，从预览可一步返回底部输入；没有正式作品时也可以续聊。顶栏先显示会话标题，只有在形成方案后才显示对应类型。生成单张图片等独立素材时，右栏直接呈现素材候选。

**用截图一的需求走查。** 用户发送“用公司的荣誉资质和技术案例做一个可演示的展项”，立即进入截图二的布局。Agent 在左栏问“现场希望观众按行业自己查案例，还是由接待人员用几分钟讲重点？”用户可点选，也可直接输入“领导参观时自动讲五分钟”。Agent 据此调用智能演示插件拟定大纲。若回答“让客户按行业筛选，再点开看详情”，同一会话改走交互页面插件。用户明确说“先给我生成一张封面”时，先生成素材，之后继续判断展项形式。走查时检查消息只出现一次，未定型时无默认类型标签，确认前后会话不跳页，生成期间底部仍可补充，以及刷新后仍能接着回答。
