## 实际能力边界

- 首页语音依赖浏览器 SpeechRecognition，已测试权限错误、取消、停止和发送状态；未进行真人麦克风验收。
- 生成视频/互动影片目前真实生成文字和脚本，媒体与交互结构为演示预设；未接入视频生成或影游代码生成。
- 附件提供名称和元数据，尚无 PDF 全文解析和自动读图。检索仍以登记说明/标签为主。
- 本机登录、成员管理和审核仍是原型逻辑，尚无服务端多租户权限或实时协同。
- 暂停只停止本地等待，远端已提交任务可能继续；已有付费图片任务重试只恢复查询。
- 密钥不进入 dist 或交付包；生成任务和媒体保留在 `.local/ai/`，不打包用户私有数据。

## 使用

双击根目录 `启动智创平台.command`（macOS）或 `.bat`（Windows），打开 http://127.0.0.1:4173。账号 `jiming`，密码 `123456`。需 Node.js 20.19+；预构建版无需安装 npm 依赖。异地使用交付包时，按 server/README.md 在本机配置自己的模型凭据，或明确选择离线演示模式。

协议依据：[DeepSeek 官方文档](https://api-docs.deepseek.com/zh-cn/)、[万相文生图 API](https://help.aliyun.com/zh/model-studio/text-to-image-v2-api-reference)。
