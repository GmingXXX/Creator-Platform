# 知识本地场：无需上传的演示流程

## 演示准备

打开当前原型首页。保留可用的模型服务配置；本次模拟的是知识本地场的资料读取，内容与素材生成仍使用平台原有服务。

资料来源为 `智创真实演示资料_20261116`，对应输入文件已内置在平台中。演示期间无需选择本地文件、上传素材或导入 Skill，也不会提前生成作品。

## 操作顺序

1. 点击左上角空间选择器，选择「新建项目空间」，填写名称并「创建并进入」。
2. 在「管理空间」中打开刚创建的空间，进入知识本地场配置，点击「使用演示知识本地场」，再点击「保存绑定配置」。名称与「知识本地场id」自动填入。
3. 返回首页，确认输入框旁显示模拟资料状态，下方显示「模拟知识本地场 · 四个演示案例已就绪」。选择一个预设提示词，按需选择模型和设计风格，直接发送。
4. Agent 自动引用该案例资料并准备配套 Skill。展开「已引用模拟知识本地场」可查看文件来源。按原有流程确认内容与素材、生成作品，预览后可进入编辑器。
5. 演示下一类案例时返回首页，使用新的空白创作需求，再选择另一个预设。

也可以在新建空间时展开「绑定ACP知识本地场（可稍后设置）」，选择演示知识本地场后一起创建。

## 四个案例

| 案例 | 自动引用的输入 | 重点演示 |
| --- | --- | --- |
| 企业鱼骨时间轴 | 星澜智造企业大事件文档、10张事件图片 | 10个事件的鱼骨时间轴，确认配图、拖动浏览、点击详情 |
| 企业智能演示 | 8页PPT大纲、6张预置概念图 | 大纲解析、平台配图或AI生成、逐页讲稿、讲解与问答 |
| 互动故事 | 泰山寻碑策划脚本、5份图片/视频/HTML素材 | 10个节点、两处选择、3种结局及节点素材编排 |
| 成果卡片组件 | 组件制作需求 | 3张悬浮卡片、参数试编辑及组件复用 |

智能演示前6页自动匹配预置概念图，第7页「储能监测案例」和第8页「下一阶段的方向」保留为实时生成位。确认大纲时可查看6张预览图，保持「为缺少配图的页面自动生成素材」开启，确认后只为两处空位调用生成服务。图片为模拟概念素材，不代表客户真实厂房或业务。对任意配图不满意，仍可放大预览、替换或重新生成。已有任务保留原方案，新建一次智能演示任务会加载新增配图。

## 模拟范围与归属

- 界面明确标记「模拟知识本地场」，不表示已经连接真实 ACP。
- 知识本地场id用于标记当前空间的绑定；手工填写普通 ACP id 不会触发模拟读取。
- 资料在发送对应案例时才被引用，按空间保存来源记录，不会一次性把全部案例放入新空间。
- 同一空间重复演示复用已引用资料；禁用AI使用、删除的资料或停用的配套Skill不会被自动恢复。
- 改绑普通ACP配置后，后续创作不再自动引用演示资料；已有作品和资料保留。
- 企业数据与故事为模拟内容。真实模型、图片/视频生成及语音服务是否可用，取决于当前服务配置。

## 本轮验收方式

浏览器验收使用原始DOCX、PPTX及媒体文件，覆盖新建空间、绑定、无需上传地发送需求、来源记录、内容确认和作品生成。外部模型与语音响应使用测试替身，避免自动测试产生付费调用；这不等于真实ACP、模型或语音服务的在线验收。

## 智能演示互动问答补充

在已模拟绑定的项目空间中，打开智能演示的“互动问答”，启用“引用项目空间知识本地场”。无需上传额外文件即可试问企业核心能力、绿色运营指标或储能监测案例；回答显示预置源文件及页码／段落。保存后观众端使用相同的本地模拟检索。未提供的信息不会编造，真实 ACP 仍未连接。详见《创建与编辑操作完善_20261118.md》。
