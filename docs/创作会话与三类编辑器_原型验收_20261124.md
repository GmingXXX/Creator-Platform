# 创作会话与三类编辑器 · 原型验收

2026-11-24。对应[三类项目编辑器讨论稿](三类项目编辑器_交互设计与插件架构讨论稿_20261124.md)。下列操作从平台正常入口进入。首次走查可选择“演示模式 · 离线示例”，独立素材生成可选择样稿。

| 从哪里开始 | 建议操作 | 可以观察什么 |
|---|---|---|
| 首页首条消息 | 发送“根据公司荣誉和技术案例做一个可演示的展项”。在会话回答“领导来访时自动讲五分钟” | 发送后直接进入完整会话，先看到原话和引用资料。未确定形式时右侧没有展项类型。回答后打开智能演示方案，底部可以继续输入 |
| 同样的资料，另起会话 | 分别要求“按行业筛选，点开案例看详情”和“观众的选择改变故事结局” | 分别调用交互页面与互动影片插件。可在右侧确认结构、素材或分支，生成后留在会话试玩。刷新、返回首页后都可从最近会话继续 |
| 交互页面编辑器 | 展开卡片样式拖入画布，双击改字或换图。配置“卡片全部点开后跳页”；另配“点继续，如果卡片已全部点开，就跳页” | 两条规则可在预览中体验出差别。图层可拖至末尾，双击改名。视频可增加语音别名并用文字测试播放动作 |
| 交互页面动效 | 在“交互”中为规则配置转场，或选视频打开“动效”。先选预设，再展开时间轴，给整页录制推进与复位 | 可以分别试看局部序列和整页交互，检查不同作用对象、暂停续播、播放结束和跳页。面板含数学家展项完整示例 |
| 智能演示 | 上传含主图和重复 Logo 的 PPTX，核对建议主题与图片用途。选“约 40 页”，调整大纲后开始生成 | 可查看单页的标题、副标题、正文、配图和讲解词，按页或整份改写、预览和撤销。图片识别可人工改类，包括同源图批量纠正 |
| 智能演示编辑器 | 拖动缩略图，复制粘贴，双击改字或换图。进入讲解编排，调一句停顿、选语音并重播转场 | 页与讲稿、标注保持关联。右栏按当前选区显示属性，当前页版式与整份设计风格有各自入口 |
| 互动影片 | 在确认图核对素材，再进画布添加拍照节点。拖连线末端至空白处，撤销，再双击节点编辑图层和事件 | 可改接分支、收起属性栏、按需查看导航图。可以走通带出口的回访路径，拍照样片支持重拍、确认和跳转 |
| 三种编辑器的共用操作 | 无选区时向助手要求生成一张封面；切换横竖屏并比较排版；调整整份风格或撤销 | 素材先独立保存在发起空间，可选目标再插入。尺寸变化会调整内容及像素动效，横竖重排时列出需复查的动效。交付检查可从导出入口打开 |
| 管理中心 | 停用某个空间的创作插件，再返回该空间观察创作入口及发起任务的反馈 | 管理员控制开放范围及模型配置，空间负责人在授权内选择；作者可以继续预览已有作品 |

## 验证边界

- 三种创作插件通过本地执行器调用现有方案、生成及作品修改流程。当前原型尚未移植到 DeepSeek Harness 的运行时。
- 浏览器验收使用离线模式或受控的模型／媒体响应。PPTX 试件包含可定位的原生图片，扁平化幻灯片、任意客户资料的主题提取和分类准确率仍需实样验证。
- 拍照与声音克隆提供标明的样片／示例音色，语音口令可以用文字模拟测试。摄像头权限、实际克隆质量和展厅拾音留待设备联调。
- 新版事件与多轨动效以平台预览为验证范围。离线运行包使用独立播放器，导出面板及包内说明列出本作品涉及的差异。
