## 制作方法

- 六套背景使用 SVG 矢量路径、渐变和透明度绘制，未嵌入标题，文字由画布中的可编辑组件承载。
- 视频使用 Python Pillow 逐帧绘制并通过 FFmpeg 编码。使用固定随机种子与 10 秒周期，确保演示可重复、可循环。
- 语音使用系统 `say` 合成 AIFF，再由 FFmpeg 转换为网页可播放的 WAV。
- HTML 通过原生 SVG 和 JavaScript 绘制受控交互，不调用网络，不读取本地文件。
- `Artwork.tsx` 使用原生 SVG 绘制展项缩略图；传入作品时按首个页面的实际组件位置、尺寸、文字与内容项绘制。每个实例使用独立 SVG 标识，避免多张卡片同时出现时遮罩互相干扰。
- 时间轴、关系图、卡片、地图、流程图、数据图表、语音波形和 HTML 样张均为原创演示构图。图表数值及文案是示例，不作为业务事实。
