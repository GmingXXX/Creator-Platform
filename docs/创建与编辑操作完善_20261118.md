# 创建与编辑操作完善（2026-11-18）

本轮范围：智能演示新建、交互页面编辑、智能演示编辑及知识本地场模拟问答。

## 使用方式

- **新建智能演示**：只选择一次设计风格。打开风格选择后可查看缩略配色与大图预览，支持窄屏。选择“无”时由内容决定页面编排。自定义风格的配色和字体也会传入实际成果；社区已有模板仍可作为创作起点。
- **交互页面编辑**：选中组件后按 Delete 或 Backspace 删除；文字输入过程中正常删字，锁定组件不会被误删。图层面板拖动可调整前后顺序，支持撤销。设计风格只在顶部保留。
- **文字编辑**：两类编辑器均支持字体、字号、字重、颜色、对齐和行距。复合组件可分别修改标题和正文。描述性的风格字体会映射为实际系统字体栈。
- **智能演示素材**：在页面制作模式中选中元素，可拖动位置、使用四角控制点缩放。图片和视频默认等比缩放，按 Shift 可自由调整；坐标和尺寸保留一位小数，保存后重新进入仍保留布局。
- **交互页面导出**：直接点击“导出管理平台运行包”下载 ZIP。包含 index.html、场景 JSON、清单、运行 JS/CSS 和实际引用的媒体资源。资源缺失或组件含未声明外部依赖会报错，不静默下载残缺包；支持取消及失败重试。

## 模拟知识问答演示

1. 在“管理空间”使用演示知识本地场并保存绑定。
2. 打开该空间中的智能演示，切换“互动问答”。
3. 勾选“引用项目空间知识本地场”；可查看名称、id、模拟绑定状态与可用资料。
4. 试问“绿色运营有哪些指标？”或“储能监测案例是什么？”，回答会显示资料摘录和源文件页码／段落。
5. 保存后点击“开始演示”，观众提问使用同一模拟检索。

索引从预置 DOCX、PPTX、Markdown 文件提取，记录源文件 SHA-256；模拟模式不请求远程问答接口。无依据的问题明确回答资料未提供。修改绑定需重新确认引用；失去空间访问权限或资料不允许 AI 使用时，不继续使用对应资料。

## 交付边界

- 模拟知识检索基于本地演示资料，不表示真实 ACP 已连接。普通 ACP 配置仍显示未连接状态。
- ZIP 已验证可在浏览器离线打开；与实际管理平台的导入协议仍需联调。在线问答、实时生成等服务不随静态包离线化。
- 字体选择使用运行设备上的系统字体及回退字体，不包含第三方字库。上传 HTML 组件支持容器位置和尺寸编辑，内部文字仍由组件自己的可编辑能力决定。
- PPTX 保留文字属性及复合组件标题、正文样式；动态素材和平台问答依然在平台中播放。
