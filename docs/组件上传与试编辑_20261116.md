# 组件上传、检查与试编辑

更新日期：2026-11-16。对应当前 V1.6 原型。

## 使用入口

素材库 → 上传素材，或画布 → HTML 交互程序 → 上传素材。

组件的主要交付形式是包含 HTML、JavaScript、CSS、图片等资源的 ZIP，不要求先制作清单，也兼容单独 HTML。

1. 上传 ZIP 后，自动识别 HTML 入口。只有一个入口时自动选中；有多个时先选择要运行的入口。
2. 展示文件、依赖、参数声明等检查结果。缺少资源时指出具体路径，并支持重新上传。
3. 点击“预览与试编辑”后才运行组件。预览与平台隔离，不开放同源访问。
4. 没有编辑接口时，说明仅支持画布外层的位置、尺寸等编辑。有编辑说明和实际订阅接口时，显示文本、长文本、颜色、数字、开关等试编辑控件。
5. 参数发送后必须收到当前预览实例的响应，才允许保存。没有连接、运行出错、修改未确认时不显示成功，也不允许保存当前配置。
6. 填写名称、用途说明后保存。素材库入口保存到当前“我的素材”或“项目共享”；画布入口保存到我的素材库，然后确认用于画布。

取消不入库。普通图片、视频、文档，以及不包含 HTML/组件清单的 ZIP 继续使用原素材上传流程。批量上传可逐个检查组件；取消其中一项不会取消其他文件。

## 普通 HTML 资源包

```text
企业展项.zip
└── 企业展项/
    ├── index.html
    ├── css/style.css
    ├── js/app.js
    └── images/cover.png
```

相对资源路径按选中的 HTML 位置解析，不依赖上传者电脑上的路径。支持的静态资源合并为独立 HTML 运行副本，保留延迟脚本、样式条件、SVG/媒体片段等行为。文件应使用 UTF-8 编码。

无编辑说明的 ZIP 仍可预览和使用，不会被标为可拆解的原生组件。

## 参数试编辑包

在普通资源 ZIP 中增加 `component.json`，并在运行代码中订阅参数：

```json
{
  "schemaVersion": 1,
  "name": "企业展示卡片",
  "description": "展示企业主题，可修改标题和主题色",
  "entry": "index.html",
  "bridge": "zhichuang-component-v1",
  "fields": [
    { "key": "title", "label": "标题", "type": "text", "default": "企业展示" },
    { "key": "accent", "label": "主题色", "type": "color", "default": "#2563eb" }
  ]
}
```

```javascript
window.ZhichuangComponent.subscribe(props => {
  document.querySelector('h1').textContent = props.title;
  document.body.style.backgroundColor = props.accent;
});
```

平台注入运行桥接代码，订阅函数必须同步更新。清单只是声明，实际接口连接后才开放试编辑。示例 ZIP 可在上传窗口直接下载，也已保存在 `output/组件上传示例/企业成果展示卡.zip`。

本轮试编辑结果作为默认配置写入运行副本，详情预览、画布嵌入和浏览器导出保持同一配置。它仍是 HTML 嵌入组件，内部元素不会自动拆分；本轮没有新增画布内参数面板、版本升级或任意源码编辑功能。

## 检查结果的含义

| 状态 | 代表什么 | 不代表什么 |
|---|---|---|
| 文件检查完成 | 已解析入口和可识别的资源引用 | 业务交互一定正确 |
| 预览文档已加载 | 文档已在隔离环境加载 | 整个组件已经全面验收 |
| 参数接口已连接 | 订阅回调执行并回应当前参数请求 | 任意内部结构都可编辑 |
| 离线能力未验证 | 尚未对用户上传组件做完整断网运行测试 | 自动承诺离线兼容 |

外部引用在预览前提示。复杂动态依赖、ES 模块工程、动态本地加载、Worker、嵌套页面等，本轮明确提示需要预构建/适配，不自动安装 npm 库，也不假装已经兼容任意 Spline/3D 工程。

ZIP 限制为压缩后 50 MB、展开后 40 MB、单文件 12 MB、HTML 入口 5 MB、250 个文件或目录。这些是本轮浏览器原型限制。普通资料 ZIP 不按组件展开。

本地文件仍保存在浏览器存储，清理浏览器数据会影响可用性；没有新增服务端组件仓库或自动依赖下载服务。

## 从素材直接新建画布

素材详情点击“插入画布”后，可选择“已有项目”或“新建交互页面”。新建时填写项目名称和屏幕分辨率（支持自定义），确认后在当前创作空间一次保存包含该素材的项目并打开画布；展示内容和展示形式保持未分类。返回或取消不创建项目，非法名称或尺寸会提示修正。个人素材用于项目共创空间时保留原件，并采用空间副本。
