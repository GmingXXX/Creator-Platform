# 智创平台：让创意成为作品，让经验成为资产

产品营销汇报稿 · 基于 V1.6 高保真原型  
编写日期：2026 年 11 月 12 日

适用场景：面向管理层、业务团队及合作伙伴的产品介绍。正文按约 12–14 分钟组织，配合演示可预留 15–18 分钟，具体随语速调整。以产品价值为主线，穿插实际使用场景。【画面】是演示提示，不需要念出。案例采用虚构的钢铁企业，不代表真实客户成果。

## 一、开场：我们希望解决什么问题

【画面：智创平台首页，停留在“您想创建什么？”】

各位好，今天向大家介绍我们正在建设的内容智能生产平台——智创平台。

它主要服务内部的策划和设计人员，面向企业展厅、博物馆和主题展示空间中的内容制作。核心目标很明确：让一个内容想法更快形成可体验的作品，让做过的项目能够为下一次创作提供积累。

在实际项目中，一份客户资料要变成观众可以点击、浏览和参与的展项，中间需要经过内容梳理、形式选择、视觉设计、素材准备和交互制作。客户提出调整后，这些环节还要继续配合。

我们希望通过智创平台，把这些工作衔接得更顺畅。策划可以更早表达和验证想法，设计可以接着精修，开发可以基于清楚的效果和操作逻辑去实现，团队也能把已经验证过的成果保存下来、继续使用。

今天展示的是已经接入部分真实模型能力的高保真原型。我们用它呈现产品的工作方式，也用它指导后续开发和实际生产验证。

## 二、产品愿景：让人提出目标，让 Agent 组织执行

【画面：继续停留在首页的 Agent 对话入口。】

如果把视角放得更远，我们认为，AI 时代的产品会逐步减少对人工操作步骤的依赖。随着智能体理解、规划和执行能力的提升，人可以把更多精力放在提出需求、表达创意、判断价值上，把查找资源、拆解任务和反复配置这些工作，交给 Agent 完成。

因此，我们理想中的产品形态，可以从一个简洁的 Agent 入口开始。使用者说清楚想达到什么效果、面向什么人、有哪些要求，Agent 理解目标后，主动补充必要信息，拆解任务，参考相应的规则和经验，再调用合适的工具组织执行。

比如制作一个企业发展历程展项，未来我们希望 Agent 能够根据客户资料和展示目标，选择合适的内容结构，遵循品牌与设计规范，调用已有模板和素材，补齐缺失资源，完成页面编排、交互配置与效果检查。使用者在关键节点确认方向，并通过持续对话调整结果。

在这样的工作方式下，人的价值会更集中地体现在创意、判断和决策上。产品的入口可以越来越简单，背后的专业能力则需要越来越完整。

这也是智创平台各项能力建设的共同方向：设计风格提供视觉规则，Skills 沉淀制作方法，模板和素材积累可复用资源，编辑画布与生成工具承担具体执行。它们共同构成 Agent 完成任务所需要的基础，也保留人随时介入和精修的空间。

今天的原型正在逐步验证这条路径。我们希望随着能力成熟，让使用者从“逐步操作工具”，走向“表达目标、确认方向、获得成果”。

## 三、产品定位：围绕展项内容组织创作能力

【画面：打开“新建项目”，展示三个创作方向。】

智创平台围绕三类内容展开。

第一类是交互程序。比如企业发展历程、荣誉资质、案例成果、产业分布，让观众通过触摸和点击主动了解内容。

第二类是演示与视频。围绕一个讲解主题，组织演示页面、讲稿和视频分镜，帮助我们把内容讲得更清楚。

第三类是互动影片。把故事拆成场景、选择和结局，让观众的选择影响体验的走向。

这三种形式，对应了展示空间里三种常见的表达需求：让人主动探索、让人理解信息、让人参与故事。

平台的生产逻辑是连贯的：从需求出发，选用已有资源，补充缺失内容，进入编辑和预览，再把有价值的成果沉淀下来。

下面我用一个实际工作场景说明这条链路。

## 四、从一句需求，形成可以继续修改的作品

【画面：回到首页，输入钢铁企业发展大事记需求；展示设计风格、Skills 与模板入口。】

假设我们接到一个钢铁企业展厅项目，需要制作一面可以触摸浏览的企业发展大事记。

策划同事可以直接描述：“为一家钢铁企业制作发展历程展项，按年代浏览，点击事件查看图文详情，适配全景屏，整体风格稳重、有工业质感。”

这时，策划先表达的是内容目标和观众体验。设计风格、技能和参考资料，可以在这个需求上逐步补充；如果已经有合适的模板，也可以直接从模板开始。

比如选择“工业蓝”，就能给后续画面一个共同的视觉方向；选择企业大事记相关的 Skill，就把相应的编排方法带进这次创作。还没确定风格时，也可以先不选择，保持探索空间。

【画面：进入创作任务，展示资源候选及完整成果。】

接下来，平台围绕需求组织内容，并检查已有的组件和素材是否适用。

能够沿用的时间轴结构、图文卡片和背景，就优先复用。需要补充的背景，可以再生成，也可以由使用者上传真实资料。

这里有一个很实际的价值：团队已有的东西能够参与下一次创作，生成能力则用来补足缺口。

得到第一版以后，我们可以继续说：“把标题改得更简洁”“突出某个发展阶段”，或者选中一个组件，只修改它的内容。

在当前已适配的组件范围内，这些结果可以进入画布，保留可编辑的结构。策划得到了一份能看、能操作、能继续讨论的初稿，设计也获得了继续加工的起点。

对售前来说，这有助于把方案讲具体；对交付来说，第一版之后的修改和完善也能够接着进行。

## 五、从初稿到精修，让创作过程保持可控

【画面：进入画布，修改文字、拖动组件，从素材库替换图片，再运行预览。】

到了画布里，设计同事可以按照熟悉的方式工作：调整位置、尺寸、文字和外观，配置页面之间、组件之间的交互，设置动效，并预览实际效果。

画布和素材库是打通的。替换图片、视频或背景时，可以从自己的素材、项目共享素材和共创社区中选择，保留原有布局和关联配置。

AI 助手也在同一件作品里继续参与。我可以让它调整选中的标题，或者生成一张新的背景候选图，确认效果以后再应用。替换背景时，前景中的内容和组件仍然保留。

这让使用者能够控制修改范围，知道变化发生在哪里，也能够撤销不满意的结果。

对于内部评审，这份可操作的作品能够帮助大家更直接地讨论内容、布局和交互；对于开发交接，画面效果和操作关系也有了更明确的参照。

交互程序还可以导出浏览器运行包，用于独立打开和演示，让评审对象直接体验作品。

## 六、从内容讲解到互动叙事，覆盖不同表达任务

【画面：展示“演示与视频”的主题、大纲与编辑界面。】

同一个企业展厅，还可能需要一段面向参观者的创新成果讲解。

在“演示与视频”中，使用者可以说明主题和受众，设置风格、尺寸以及页数或时长，也可以补充参考资料。平台协助形成大纲、讲稿或分镜草稿，再由使用者调整内容和顺序。

这一部分当前已经能够展示从主题到可编辑内容结构的过程，后续还需要完善真实成片和演示文件输出。

【画面：展示互动影片创建窗口，再进入节点画布与分支预览。】

如果希望观众参与其中，我们就可以使用“互动影片”。

例如设计一次未来工厂探索：观众进入不同车间，选择不同技术路线，最后看到不同的结果。

策划可以先描述体验流程，上传脚本，让平台协助整理节点草稿，再逐个确认内容、去向和素材。每个节点可以使用图片、视频或 HTML 交互内容。

也可以什么都不上传，直接进入空白节点画布，手动搭建。这样既能支持已有完整策划的项目，也能支持从一个想法开始逐步探索。

三类创作能力放在一起，我们就能围绕展示目标选择表达形式，让同一主题有更多呈现方式。

## 七、让团队经验可以被找到、被理解、被复用

【画面：依次展示项目、素材库、Skills，最后停留在共创社区。】

智创平台的另一项重点，是把创作过程中产生的价值保存下来。

项目中保存的是可以继续编辑的作品；素材库中保存的是图片、视频、音频、组件和参考资料；Skills 保存的是可以反复采用的制作方法。它们对应作品、资源和方法三个层次。

共创社区把适合共享的内容集中起来，包括展项模板、展项素材、Skills 和设计风格。

找模板时，策划可以按“发展历程”“荣誉资质”“案例成果”这样的展示内容筛选，也可以按展示形式寻找合适的结构。选中模板后，创建自己的副本继续编辑。

素材的沉淀也可以更完整。除了效果本身，还能保存关联文件、提示词和制作方法。看到一个喜欢的效果，使用者可以把这组资料带入新的创作需求，参考它继续制作。

个人整理出来的技能包也可以上传，在界面中预览、管理，再投稿到社区。社区通过审核流程明确共享内容的质量要求，设计风格则由平台侧统一维护。

在项目组织上，平台区分个人空间和具体项目空间；个人素材与技能可以持续使用，项目采用的资源保留独立副本。多人协作部分，目前通过原型表达成员、权限和共享规则，后续需要进一步落地实时协作服务。

这部分的长期价值，是让一次项目的投入留下可以再次使用的成果。随着有效模板、组件和方法逐步积累，后续项目就有更多可靠的起点。

## 八、平台带来的业务价值

【画面：回到完整展项预览，最后返回首页。】

从业务角度看，我们希望智创平台带来三个变化。

第一，缩短从想法到可讨论作品的距离。策划能够更早把内容和体验表达出来，客户与团队也能围绕具体效果形成共识。

第二，让修改过程更加连贯。AI 辅助、手动画布和素材替换围绕同一件作品展开，减少内容在不同制作环节之间重新整理的工作。

第三，让项目经验持续积累。模板保留结构，素材保留效果，Skills 保留方法，共创社区让这些积累有机会被更多项目采用。

对策划，它提供从需求到初稿的帮助；对设计，它提供可继续精修的结构和资源；对开发，它提供更明确的产品行为参照；对团队管理，它提供观察和积累生产能力的载体。

这些价值还需要通过真实项目检验。接下来可以选择一个典型展项，记录初稿形成时间、修改轮次、已有资源复用情况，以及最后的交付质量，再逐步扩大应用范围。

我们希望智创平台最终形成一种持续积累的内容生产方式：每一次创作都能借助已有经验，每一次完成又能留下新的经验。

让创意成为作品，让经验成为资产。这就是智创平台正在推进的方向。

## 附一：30 秒产品介绍

智创平台是面向展厅策划和设计团队的内容智能生产平台，围绕交互程序、演示与视频、互动影片三类内容，把需求描述、资源复用、AI 辅助和可视化编辑衔接起来。它希望帮助团队更快形成可以体验和修改的作品，并通过模板、素材、Skills 和设计风格，把项目经验积累下来，服务后续创作。目前已形成接入部分真实模型能力的高保真原型，正在向实际生产应用推进。

## 附二：配合汇报的演示节奏

| 顺序 | 建议展示 | 对应价值 |
|---|---|---|
| 1 | 首页与三类新建入口 | 一眼理解产品服务谁、能做什么 |
| 2 | 企业大事记需求、资源候选、完整成果 | 展示需求到作品的核心链路 |
| 3 | 同一作品连续修改、画布精修、替换素材 | 说明生成之后仍然可控、可编辑 |
| 4 | 演示大纲与影片节点画布 | 展示不同内容表达方式 |
| 5 | 共创社区预览模板、素材资料包和 Skills | 说明项目经验如何沉淀与复用 |
| 6 | 回到完整作品与首页 | 收束到业务价值和真实项目验证 |

现场演示宜准备好一份完整案例，集中展示少量连续操作。模型生成环节可采用已完成的真实任务记录，或现场发起后切换到其他环节；使用离线演示模式时明确说明，不把示例结果当作实时生成结果。企业年份、荣誉、技术和案例应使用已核实资料，虚构示例应标明。
