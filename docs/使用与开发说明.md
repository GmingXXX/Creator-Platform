# 智创平台 · 高保真 Demo V1.6

本版本用于产品规划沟通与前端开发参考。工作台采用统一的浅色、细边框与紧凑控件；内容风格通过设计风格独立配置。

## V1.6 创建与编辑更新

项目三类入口现为“交互页面 / 智能演示 / 互动影片”。“交互页面”沿用原交互程序项目的画布与数据；下文旧版功能说明中的项目类别名称按此对应，HTML 嵌入程序的技术描述不受影响。

浏览器刷新后统一回到首页，未登录时仍先进入登录页。已保存作品、素材和未发送草稿保留；正常站内跳转与首次打开项目链接仍进入对应页面。

- 首页“新建项目”选择智能演示、互动影片后直接打开创建窗口；打开项目列表中的现有项目直接进入对应编辑器。
- 交互程序的展示内容和展示形式默认“无”，可先创作；投稿时两者至少填写一项。显式未分类使用 `displayForm:null`，旧项目 `displayForm` 未设置时沿用原 `type` 分类。
- 项目与社区共用四个项目类型按钮及紧凑下拉筛选。用户可见名称统一为“设计风格”。
- 画布单选组件按画布对齐，多选按未锁定组件整体范围对齐；空白/模板项目同样可选择 DeepSeek 修改当前组件或页面、添加已适配的原生组件。离线规则需要明确选择演示模式。
- 右侧 AI 支持万相候选图生成、查询、预览后应用到背景或选中图片，前景结构不被替换。
- 互动影片可不填体验流程、不上传脚本，直接进入空白节点画布；也可使用 DeepSeek 生成节点草稿，确认内容、去向和素材后创建。HTML 节点隔离运行，仍需在画布中连接下一节点。
- 智能演示支持真实大纲/分镜草稿、可编辑讲稿与顺序、尺寸和数量设置。视频合成不在本轮实现范围。
- TXT/Markdown/DOCX/PPTX 支持有长度限制的文字提取；PDF、旧版 DOC/PPT 仅保存为参考资料，界面明确提示暂不支持解析。图片理解、视频理解未接入。

## 模型服务与使用方式

先运行 `npm run build`，再运行 `npm start`，打开 http://127.0.0.1:8787。开发时同时运行 `npm run ai:server` 与 `npm run dev`，使用 http://127.0.0.1:5173。登录仍为 `jiming / 123456`。

首页默认使用 DeepSeek Flash，也可选择 DeepSeek Pro 或明确标注的离线演示模式。模型选择以供应商当前接口为准。DeepSeek 负责策划、结构化编排和受限多轮修改；万相负责图片生成。服务端配置与接口见 [server/README.md](../server/README.md)。密钥只由本机服务读取，不进入网页、静态构建或交付包。

首页改为“您想创建什么？”，预设需求采用文字胶囊与刷新按钮；下方“从最佳模板开始”按收藏及复用综合热度排列，可预览并创建独立副本。录音入口在发送键左侧；取消保留原稿，停止后转写到输入框，发送会结束录音后提交。语音依赖浏览器 SpeechRecognition；不支持或权限失败时明确提示，可继续文字输入。

项目按空间隔离；个人素材及 Skills 跨空间常驻。项目使用个人或社区资源时固定副本与版本，个人源后续删除或修改不影响项目已固定资源。选材入口区分“我的素材／项目共享／共创社区”。共创空间下拉中的“成员与共享设置”是本地成员权限演示，尚无真实邀请、多人同步及服务端空间鉴权。

Skills 使用“全部／收藏”及来源下拉筛选，默认提供六个可预览样例。社区保留四板块，项目类型平铺，用途及展示形式使用紧凑下拉；智能演示、互动影片增加样例工程。

真实生成失败会保留需求并显示错误，不以示例内容冒充成功。图片任务按原任务标识恢复查询；暂停只停止本地等待，已提交到供应商的任务可能继续。智能演示、互动影片的创建窗口可由模型生成大纲、分镜及节点草稿，用户确认后保存工程；媒体需上传或选用已有素材，不代表已渲染影片或完成全新交互程序开发。全新 HTML／未知组件不在真实生成范围内；已适配气泡、时间轴和卡片可生成可编辑配置。

当前素材检索仍基于登记说明和标签，尚无自动读图或向量检索。新建演示与互动影片窗口可提取支持格式的有限文本；其他入口上传的附件仍以名称和元数据为主，不能视为已阅读完整 PDF 或图片。当前 API 服务仅支持本机单用户演示，上线需另行实现真实身份和授权。


## V1.4 更新：统一项目分类与共创入口

当前侧栏保留「首页、项目、素材库、Skills、共创社区」五项。「新建项目」是创作入口，在同一弹窗选择「交互程序」「智能演示」「互动影片」：

- 交互程序：继续选择「从空白画布新建」或「从模板新建」。空白项目填写名称、展示形式和分辨率；可以返回上一步，展示内容不限制创建。从模板开始时进入已筛选交互程序的社区模板。
- 智能演示：进入原演示中心的制作能力，继续选择讲解演示或视频创作。
- 互动影片：进入原造梦机的节点工作流能力，制作场景、选择和分支故事。

新建的是当前空间中的一份创作项目；侧栏顶部的「信泰企业展厅」等仍是协作空间，不会因为新建项目再创建一个空间。

共创社区有「展项模板、展项素材、Skills、设计风格」四个板块。Skills 侧栏用于管理自己的上传和已采用能力；社区用于发现、预览和采用公开版本。设计风格由开发团队维护，集中在社区展示，不再占用侧栏独立入口；首页和画布中的设计风格快捷选择保留。

### 项目类别、展示内容与展示形式

三个维度独立保存和筛选：

| 维度 | 选项与作用 |
|---|---|
| 项目大类 | 交互程序、智能演示、互动影片；决定继续编辑时进入哪个工作台 |
| 展示内容 | 企业概览、发展历程、荣誉资质、产品与服务、技术创新、案例成果、产业与业务布局、产业链与合作生态、工艺与业务流程、经营与发展数据、文化与人物、文博与知识科普；按策划内容寻找作品；登记时可多选，列表按所选用途筛选 |
| 展示形式 | 时间演进型、关系图谱型、卡片浏览型、空间分布型、流程架构型、媒体叙事型、数据总览型；只用于交互程序 |

项目和社区模板都先按三大类筛选，再按展示内容查找。展示内容使用下拉筛选；选择交互程序后显示展示形式下拉。新建空白项目可以暂不分类，交互程序投稿模板时展示内容和展示形式至少填写一项。旧作品保留原展示形式，并对未登记用途的标题作兼容推断；这是演示规则，不代表真实内容识别。

## 选材、素材说明与画布打通

以下选材与编辑能力沿用 V1.3，并适配当前项目与素材划分。

围绕“找到合适素材、知道来源、用进作品、继续修改”衔接生产操作。

- 创作任务展示真实可用的背景候选、来源和匹配依据；没有候选时明确提示，可以生成背景或自行选择/上传。选择后的资源实际写入展项，完整预览保留文字、组件和交互。
- 素材详情新增“素材信息”：文件类型、大小、可读取的尺寸/时长，以及内容说明、业务说明、适用对象确认、用途、是否允许智能体检索。上传文件的业务身份不从文件名猜测；未识别的内容标为待补充。用户说明与系统信息分开保存。
- 画布左侧新增“素材”，图片、视频、音频、HTML 插入与替换、页面背景、卡片图片，以及讲解演示、视频和互动影片的媒体选择，统一进入选材窗口。窗口分我的素材、项目共享、共创社区（内置素材在我的素材可用），可预览、搜索或上传；兼容类型才可选择。演示文稿和未渲染的视频工程不能直接当成图片或 MP4 插入。
- 拖入素材可以新建组件，拖到同类型媒体组件上可以替换；替换保留位置、尺寸、动效和交互，可撤销。锁定组件不接受替换。HTML 通过隔离框架运行，只编辑外层布局；自包含 HTML 也随浏览器运行包导出，外部依赖需要另行打包适配。
- 左上角 Logo 返回首页，编辑器先保存当前内容。成功提交的提示词从首页输入框清空；未发送或提交失败的需求保留。画布两侧面板使用双箭头收起和展开。
- 所有可编辑工程统一进入项目，取消归档入口；旧归档记录恢复为正常列表项，删除状态不变。项目删除后可从项目回收站恢复。智能演示、互动影片的工作台保留“查看项目”，指向当前工程所属空间和类型。

### 素材归属与调用规则

个人空间保存自己的原始素材，项目空间保存共享及引用副本；共创社区保存审核发布的固定版本；内置素材提供平台样例。复用公共资源时，在当前空间保存带来源和版本记录的独立副本。同一来源同一版本重复采用会复用已有副本；新版本需要重新采用，不会静默覆盖旧作品。当前空间的素材不会因为填写标签或说明自动发布到社区。

自动候选同时检索当前空间、平台内置和社区资源，按说明/标签相关性排序，同等相关时略优先当前空间。未登记内容且没有业务说明的上传素材、关闭智能体调用的素材、仅作参考的素材，不参与自动成品选材。明确指定客户真实图片时，需要匹配已确认的业务对象；不确定时提示补充，不能以通用生成背景代替客户实拍。用户仍可手动选材；将文件作为参考与把它作为最终画面是两个用途。

使用模板、素材包和工程时会检查嵌套资源引用；其他空间的私有依赖不可因包装成公共模板而被带入。当前 Demo 尚未实现“私有依赖授权发布”的完整后台流程；出现这种模板时会明确提示先处理依赖，不能冒充已完成发布授权。这里是本地状态与引用校验，生产环境还需服务端权限、存储访问控制和版本管理。

### 识别与组件能力边界

本版实际读取文件属性，继承已有内容说明，并允许人工补充业务事实；检索采用可解释的演示规则，未接入真实多模态识别与向量检索；模型生成已在 V1.5 接入。未来可在同一数据结构接入自动内容识别，再让使用者确认业务身份；无需要求用户手工填写大量标签。

AI 语音气泡、时间轴、卡片基于已注册的原生组件生成配置，能够编辑开放属性。未知新组件输出为“交互程序 · 待适配”示例，不宣称任意生成代码能自动变为原生组件。首页语音识别使用浏览器能力；展项内语音问答、语音合成及新组件协议适配仍需正式开发。

## 创作入口与成果归属

| 创作入口 | 可编辑工程的管理位置 | 继续编辑 |
|---|---|---|
| 首页智能创作 / 新建项目 → 交互程序 | 项目 → 交互程序 | 原生画布；嵌入式程序保留外层布局编辑与适配说明 |
| 新建项目 → 智能演示 → 讲解演示 | 项目 → 智能演示 | 原演示编辑器，保留页面与讲稿 |
| 新建项目 → 智能演示 → 视频创作 | 项目 → 智能演示 | 原分镜编辑器，保留画面、旁白与时长 |
| 新建项目 → 互动影片 | 项目 → 互动影片 | 原节点画布，保留场景与分支 |

各工作台的最近创作、侧栏最近草稿和项目卡片指向同一份工程。项目可搜索、筛选、重命名、复制、预览、继续编辑、投稿及删除恢复；复制得到独立工程，继续编辑会进入对应制作工具。

素材库只展示可复用文件与组件：图片、视频、音频、组件、文档资料。HTML 嵌入程序归到组件，保留“可编辑外层布局、内部能力需适配”的说明；上传的 PPT/PPTX 归到文档资料。可编辑页面、分镜和节点工程均不再作为素材卡片重复出现。

演示工程目前保存页面与讲稿，并可导出 JSON；尚未生成真实 PPTX。视频工程可预览当前分镜、导出工程 JSON，下载预置 MP4 样片，但修改分镜不会重新渲染成片。未来接入真实输出服务后，生成的 PPTX、成片 MP4 作为独立文件归素材库，工程继续留在项目。当前已上传的实际媒体文件和预置样片可作为素材使用，不能用工程记录冒充已完成的文件输出。

### 旧版本兼容

刷新后保留旧工程 ID、空间、内容、素材引用和删除状态。旧版素材库中的工程索引保留为隐藏别名，用于解析历史链接与依赖，不再显示成重复素材卡片。可恢复的旧工程快照归入项目；旧公开工程素材转为对应模板，收藏和投稿记录继续关联审核版本。旧素材工程详情链接会引导到正确编辑器、模板或项目回收站，无须为升级重置数据。

## 围绕当前作品继续创作

首页继续采用文字提示，不新增评审顶栏或图片提示卡；文件入口为回形针。设计风格入口仍叫「设计风格」，下拉第一项「无」用于取消绑定，不影响继续创作。

成果页左侧可以连续描述修改，右侧展示当前完整作品。支持把修改范围切换到整个作品、某一页或某个组件；画布右侧「AI」默认跟随当前选中对象。示例输入：

- 「把背景改成暖色」：修改当前范围的背景，保留原有组件和交互。
- 「把标题改为创新的足迹」：更改标题；指定文字组件时仅修改该组件。
- 「增加一个 2025 年节点：全球布局」：向当前范围的时间轴追加内容。
- 上传图片后输入「用附件替换背景」，或选中图片组件后输入「用附件替换图片」。

修改记录刷新后保留；可撤销最近一次 AI 修改。若之后发生手动编辑，旧修改不会通过整份快照回滚覆盖手动内容。不支持的描述会说明未修改，并保留输入；旧演示作品采用受控规则；DeepSeek 新建作品使用真实模型返回的受校验修改。单独生成的素材通过「以此素材继续创作」携带资料进入新需求。

资源补齐完成后，主成果始终显示完整展项；新增背景另列在下方，可以单独查看。

## 空间与删除恢复

侧栏顶部可切换「个人空间」「信泰企业展厅」「东莞博物馆」「ai小镇展厅」。作品、未发送需求和上传/生成素材跟随创建时的空间；公共社区和内置素材可以复用。原来的样例保留在个人空间，项目空间没有虚构客户成果。当前只是同一设备上的项目归属演示，尚无真实成员权限和多人同步。

最近草稿悬停或键盘聚焦可见删除按钮，项目卡片的更多菜单同样可删除。交互程序、演示、视频和互动影片工程都进入「项目 → 回收站」。恢复后保留原内容与资源引用；删除工程不会删除独立的媒体文件或已发布社区版本。素材库删除真实素材时会检查作品引用，被引用的素材不能直接删除。未发送需求删除前会确认。旧版本的归档记录自动回到正常列表，后续统一使用搜索、筛选和回收站管理。

## Skills 上传、投稿与采用

在 Skills 点击「添加技能」，上传 ZIP。包内需有根目录或一层文件夹内的 `SKILL.md`，可附预览图、参考资料及脚本。添加前会展示名称、说明和文件清单；保存后可下载原包。页面提供可直接回导的示例 ZIP。包内脚本只保存，不自动执行；非法路径、超限或不完整的压缩包会提示具体原因。

自己的技能可编辑说明、输入、步骤与版本，提交到共创社区后先进入审核。管理员检查说明、示例、输入输出和依赖文件，通过后发布独立版本；待审或退回版本不会覆盖已有公开版本。普通使用者从「共创社区 → Skills」预览并选择「添加到我的 Skills」，或直接「带入首页使用」。采用时固定当前版本，重复采用同一版本复用已有副本，社区后续更新不静默覆盖已采用能力。

首页 Skills 快捷入口也会先采用固定个人版本。同来源同版本不重复列出；原草稿选用的老版本保留，不随社区更新而改变。

设计风格属于开发团队维护的共享能力，当前没有个人设计风格上传和投稿流程。

## 推荐演示路线

1. 首页选“企业发展大事记”，修改需求并发送；展示需求理解、候选素材与来源、资源确认及继续创作。结果进入原生画布，2560×1120 尺寸已带入。
2. 在画布选中组件，拖动、调整大小，修改文字或时间轴内容，从“素材”或属性面板替换图片/视频，使用撤销。运行预览点击事件查看详情；返回后保持编辑状态。
3. 导出“浏览器自包含（ZIP）”，解压运行。另两种播放器格式提供示例协议与数据清单。
4. 返回首页，打开“新建项目”，展示三类入口及交互程序的空白/模板两种起点；到项目中展示三大类、展示内容与交互程序展示形式的区别。
5. 打开“共创社区”，先看展项模板并快速复用；切换“展项素材”，展开完整资料包，点击“一键同款”回到首页。原有未发送需求会保留，新草稿携带参考文件、提示词、Skill 和参数。
6. 在社区 Skills 查看效果与技能包，采用固定版本到个人 Skills；展示 ZIP 上传与个人技能投稿入口。切到社区设计风格，先看六种风格，再进入颜色、排版、组件、动效规则。
7. 从项目、素材库或个人 Skill 详情提交社区，显示待审核。账户菜单切换审核员并打开审核管理，校对后通过；社区才出现新发布版本。项目投稿会确认展示内容和展示形式。
8. 从“新建项目 → 智能演示”打开企业演示，编辑内容与讲稿，开始讲解、追问、继续；保存后从“项目 → 智能演示”找到同一份工程。切换视频创作，查看分镜、旁白、时长与工程预览。
9. 从“新建项目 → 互动影片”打开节点画布，拖动连线，运行并探索两个结局；返回“项目 → 互动影片”可以继续编辑同一工程。

口语稿见 `docs/智创平台_实际使用者视角演示汇报稿_V1.4.md`。旧版演示稿保留供追溯。

## 实际操作与模拟边界

| 范围 | 当前行为 |
|---|---|
| 首页及模型 | 模型选择、文件上传、风格与 Skills 选择实际记录；DeepSeek 模式发出真实请求，离线演示模式使用预设场景 |
| 创作任务 | 有等待资源、暂停、失败、重试、成果入库；侧栏可找回未完成任务 |
| 原生画布 | 真实组件数据、拖动、缩放、旋转、多选、图层、页面、内容修改、属性、动效、命令、交互和预览 |
| 项目与社区 | 三类工程统一管理；社区分模板、素材、Skills、设计风格。模板复制后独立编辑，投稿固定版本快照，审核通过后公开 |
| 素材与 Skills | 文件、组件与工程分开；素材同款携完整资料包。技能支持 ZIP 上传、审核发布及固定版本采用，技能说明可作为真实模型参考，不执行上传的任意脚本 |
| 图片、视频 | 提供原创 SVG 背景、真实预置 MP4/WAV；DeepSeek 模式下图片通过万相真实生成；演示模式使用样例，视频脚本编辑不会冒充已重新渲染成片 |
| 互动影片 | 沿用造梦机的节点编辑、连线、分支条件、流程检查与双结局试运行；不提供真实视频推理与影游引擎部署 |
| 导出 | 浏览器 ZIP 为可离线运行成果；播放器 ZIP/JSON 是协议示例，尚未适配真实硬件 |
| 登录与角色 | 本地模拟身份，不是生产认证服务 |

## 数据保存

作品、任务、审核与草稿保存在本机浏览器 localStorage，上传原文件保存在 IndexedDB。刷新可恢复；无云同步。不同地址/端口或不同浏览器有独立数据，因此日常演示请固定使用 4173。

“重置演示数据”会恢复初始样例，保留上传媒体并留一份本地重置前记录。重要作品请先导出。清除站点数据会删除本机保存的内容。

## 开发

```sh
npm install
npm run dev
npm run build
npm run test:coverage
npm run test:e2e
```

开发服务 `127.0.0.1:5173`，另运行 `npm run ai:server` 提供 8787 API；双击启动器的交付服务 `127.0.0.1:4173`。测试使用本机 Chromium，可通过 `PLAYWRIGHT_CHROMIUM_PATH` 指定可执行文件。首次在其他机器测试需安装 Playwright Chromium；离线导出专项另支持 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 指定浏览器。

核心目录：`src/domain` 负责作品 Schema、状态、生成场景、上传与导出；`src/features/editor` 是原生编辑器；`resources` 是资源与审核；`studios` 是演示、视频与故事；`public/media` 为本地原创素材。所有 React 页面共享同一套 UI 基础组件与状态。

21st 组件已通过 MCP 获取源码并参考改造：Sidebar 用于折叠导航结构，Input Bar 用于输入区域和插槽组织，Morphing Dialog 用于详情展开的视觉参考。源码与来源保留在 `output/21st组件参考源码`；最终控件统一为本项目的 Radix 组件与设计 Token。未使用 21st 托管 AI 生成。
