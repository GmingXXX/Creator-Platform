# 内容智能生产平台｜详细功能、状态与前置依赖

版本：2026-11-17 最新范围版；目标：内部使用。配套：[整体计划](07_整体开发计划_最新版.md) · [三人排期](09_三人开发排期_最新版.md) · [任务表 CSV](10_三人任务排期_最新版.csv)。

## 阅读规则

- **已实现（独立工具）**：用户已确认的独立制作能力；仍需接入本平台，并验证接入后可用。
- **部分实现（独立工具）**：基础已有，明确存在缺项。
- **待确认（独立工具）**：需用真实工程和调用结果确认；排期已安排核查，并在对应工作包中预留接入及常用能力补齐。
- **待开发**：本平台正式能力尚未确认完成。已有原型界面、代码或本机模型演示可评估复用，但不据此计为正式完成。

工作包编号与三人排期逐一对应。同一工作包可覆盖多条功能，**不重复计算人天**。表中的前置依赖是功能关系；具体开始条件和先后顺序以排期表为准。

## M1｜整体智能体架构与 Harness 工程

让 Agent 理解需求、调用真实工具、检查结果，并在同一作品上持续修改。Harness 是让这些步骤能够保存、恢复、受控运行的配套工程。

**实现方式：一个统一的任务协调入口，调用三个制作工具和组件编程工具；不为每种能力另建一套任务系统。**

组件两条链路共用隔离运行、检查和打包基础，但分别排期、分别验收。
