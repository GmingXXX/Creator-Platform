# 多方参考与制作经验：原型实现说明

依据：[模板、创作资料包与 Skills 关联及复用流程讨论稿](模板、创作资料包与Skills关联及复用流程_讨论稿_20261117.md)。

本次落实已确认的两个操作流程：在 Agent 中按需整理制作经验；按用途组合多个展项参考。创作资料继续从素材卡片详情内查看。

## 1. 建议体验顺序

1. 在首页点击“添加参考展项”，选择当前空间作品或社区模板。为 A 选择“交互方式”，为 B 选择“UI 风格”；按需选择来源中的页面或组件、填写补充说明。
2. 输入当前客户的需求、事实及素材，发起创作。参考会与任务一起保存，并进入模型上下文。也可以从项目卡片菜单或社区模板详情点击“参考此展项创作”，逐个追加到当前草稿。
3. 生成后在 Agent 中查看参考；打开编辑器，手动改文案、排版，或让 Agent 调整当前作品。
4. 点击 Agent 的“整理制作经验”。默认整理整个作品；选中页面或组件时，也可以点击“整理当前范围”。
5. 查看“做了什么、参考了什么、作了哪些调整、可复用做法、尚待验证”五部分，使用“修改整理结果”补充、修订。
6. 继续制作后再次整理，已有人工修订会保留；摘要更新版本并保留整理历史。需要形成通用方法时，点击“提炼为 Skill”，检查方法说明、输入和步骤后保存草稿。
7. 对于有明确关联素材的作品，可从该素材卡片的既有“创作资料”页签查看经验摘要。不会为了展示资料而把作品额外复制成素材。

## 2. 多方参考如何落地

| 环节 | 本次行为 |
| --- | --- |
| 来源选择 | 当前空间作品、社区模板；加入时校验空间权限和相关素材的 AI 使用许可 |
| 分别表达用途 | 交互方式、UI 风格、内容组织、局部效果分别记录；同一来源可以用于不同维度 |
| 整体与局部 | 可选择整个来源展项、页面、组件、故事节点或分镜；补充说明用于表达目标区域和特殊要求 |
| 保留草稿 | 添加、编辑、移除参考不会清空原需求、附件或其他来源 |
| 固定版本 | 保存来源版本及结构快照；源作品后续修改不自动改写已选参考 |
| 模型上下文 | 按维度提供结构、样式或交互信息；不把来源客户的正文与媒体作为本次客户事实传入 |
| 实际采用 | 原型可确定应用的属性才标为“已采用”，同时记录具体属性；其余保留“参考候选” |
| 后续移除 | 仅改变后续参考上下文，不立即重绘当前作品；此前实际采用记录保留在历史中 |

明确写出可识别的作品全名及参考维度时，支持自然语言识别；名称不明确时通过选择器消除歧义。跨空间私有作品不会被自动纳入。

原型可自动应用的范围有限：单一、无局部限制的整体 UI 参考，可以应用支持的背景色、文字色、强调色、圆角和字号层级；单一整体交互参考，可在没有冲突要求时选择现有原生组件结构。已经选择的项目设计风格优先保留。

同维度多个来源、局部范围、自由文本补充说明或需求中的局部限制，不自动全局套用，界面会提示按范围交由 Agent 处理。布局、自定义交互、复杂动效不会被声称已完整还原，实际能力仍受现有编辑工具约束。

## 3. 制作经验如何保存

- “整理制作经验”是用户主动触发的快捷操作，生成或手动保存后不强制弹窗。
- 本地演示模式依据当前结构和已有修改记录整理，不调用模型；真实模型模式调用现有文本模型接口。
- 首次整理手动作品时，仅分析当前成果；没有修改记录就明确说明，不推测修改原因或现场效果。
- 摘要独立于画布版本保存，撤销画布修改不会删除经验；旧编辑快照也不会覆盖新整理结果。
- 人工修订按段落保留，包括主动留空；新整理版本保留最近 20 个历史版本。
- 整理期间作品、摘要或权限发生变化，迟到结果不会覆盖后续修改。模型失败、取消和格式异常保留原摘要。
- 真实模型仅接收可读文案和结构，不传原始媒体地址、HTML 源码或命令；调用前后检查素材 AI 使用许可。
- 经验同步到同空间、明确关联的私有素材资料包；不回写借用的社区素材。

## 4. Skills 与共享

“提炼为 Skill”形成当前空间的私有、未启用草稿。用户可以创建新方法，或针对已有 Skill 保存一份独立改进建议，后者不覆盖原 Skill。

制作经验、整理历史、内部参考及其关联标识默认不随作品或素材投稿公开；原有可复用工程内容照常走投稿流程。这个边界也应用于已在审核中的旧快照，避免批准时把新增私有记录带入社区。

## 5. 验证与范围

构建与自动化验证：

- `npm run build` 通过，包含 TypeScript 检查和生产构建；原有大文件打包提示仍存在。
- 全量单元/集成测试 79 个测试文件、847 项通过。
- 按仓库配置的覆盖统计范围，行/语句覆盖率 98.49%、函数 98.91%、分支 90.73%，均超过 80% 门槛。
- 浏览器回归分批覆盖 25 项流程，包含新增三项完整体验，以及已有对话、编辑器、智能演示和互动影片流程。
- 小屏 1024 × 768 下，长经验摘要与多方参考在独立区域滚动，输入框和发送按钮保持可见；继续修改后自动定位最新答复。

模型测试使用模拟响应，验证请求上下文、权限边界、保存和回退行为；不代表已验证真实模型的设计质量或现场设备表现。
