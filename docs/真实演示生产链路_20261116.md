# 智创平台真实演示操作说明

## 当前入口与资料

打开本地平台 http://127.0.0.1:4173 。真实生成、语音和问答需要本地 AI 服务及联网；项目、上传文件和草稿保存在当前浏览器。刷新回到首页，原作品和草稿仍可从项目或继续创作任务进入。

推荐使用 `output/智创精简演示输入_20261116.zip`。旧完整资料包保留用于兼容回归，不作为本轮演示默认输入。企业名称、经营数据和互动故事均为虚构演示。

首页预设提示词只填入需求，不自动发送。选择模型和设计风格后，可通过回形针添加文件或文件夹。Skills 页面提供“从社区添加”和“上传技能”；启用后按任务自动匹配，不需要在首页指定。社区添加首次默认启用，重复添加保留原启停状态。技能正文作为模型参考，不执行上传包里的任意脚本。

从“项目”右上角新建时留在当前项目空间。三类新建表单的“返回上一步”回到类型选择，保留当前草稿；右上角关闭结束本次创建。

## 项目空间与成员权限（2026-11-17）

左侧空间切换菜单新增“新建项目空间”。填写名称和可选说明后，创建者成为负责人；可以立即邀请成员，也可以先开始创作。原有个人空间和三个预设空间保留。空间、成员、邀请及权限体验身份保存在本浏览器，刷新仍回首页。

“成员与共享设置”支持按账号或邮箱添加邀请，指定编辑者或查看者；待加入邀请可修改权限、撤销或复制演示说明，并通过“模拟接受邀请”体验加入过程。加入后可修改权限或移除成员，负责人不可降级或移除。

| 角色 | 可操作范围 |
| --- | --- |
| 负责人 | 创作项目、管理共享素材、邀请和管理成员 |
| 编辑者 | 创建和编辑项目、管理共享素材；不能管理成员 |
| 查看者 | 浏览项目、运行预览；不能修改项目或上传共享素材 |

个人素材与 Skills 仍归个人，可在不同项目使用；项目采用的共享资源保留固定版本副本。成员窗口的“本地权限体验”可切换已加入身份，侧栏“退出权限体验”恢复负责人。查看者打开编辑器链接会进入预览；生成过程中权限变化，晚返回结果不会写入原空间。重置演示数据保留空间、成员和上传文件；任一空间处于只读身份时不允许全局重置。

**范围说明：本轮完成本地原型的创建、邀请状态和操作权限流程。尚未发送真实邀请，也未实现跨账号或跨设备的实时协作；生产接入仍需要账号系统、服务端权限及协同同步。**

## 项目空间与 ACP 知识本地场（2026-11-17）

每个业务项目空间可绑定一个已有 ACP 知识本地场，同一空间内的交互页面、智能演示和互动影片共用该配置。绑定采用唯一标识确定目标、名称用于显示；同一标识不能同时绑定其他空间。个人空间不绑定项目知识本地场。

入口为侧栏空间菜单的“知识本地场设置”，也可在新建空间时填写。负责人可绑定、更换或解除；编辑者与查看者只读。刷新保留配置。首页项目创作输入框显示当前知识本地场，可打开设置。

对话附件、项目共享素材、智能演示参考资料、互动影片脚本与节点素材、作品补充资料及配图上传，在读取开始时记录空间与目标快照，异步完成后复查上传权限。批量资料共用开始时的目标。上传过程中切换空间或更换绑定，不会将文件转投新目标；历史文件的目标记录也不回写。个人素材库及素材选择器的“我的素材”上传保持个人归属；跨空间复制和社区发布不携带原知识本地场目标。

**当前范围为本地绑定配置和上传归属记录，状态为“ACP未连接”。文件仍保存在智创，未提交 ACP；目标记录不是待同步队列，不会在接入后自动补传历史文件。当前不读取 ACP 知识本地场列表，也不提供 ACP 检索或引用。**

真实接入需要 ACP 的身份与权限、知识本地场查询、文件写入及处理状态、检索与来源引用等接口。正式上传须由服务端解析绑定、核验写入权限，并根据 ACP 返回的目标标识及文件标识确认入库，不能仅依赖前端传参或模型判断。

## 1. 企业大事件 → 鱼骨时间轴

上传企业大事件文字和三张示意图片，或使用首页“企业鱼骨时间轴”的添加示例资料入口。模型先整理事件、年份、详情和配图关系。

在右侧确认内容时，可修改文本、点击配图放大、替换或移除图片。缺失的配图可以逐张编辑描述并生成，也可勾选自动补齐后生成作品。客户提供的图片不会被批量生成覆盖；中途失败保留已完成素材，再次继续查询原任务。

完成后在右侧体验可拖动、可点击详情的鱼骨时间轴，按需进入交互页面编辑器。顶部设计风格左侧的机器人按钮打开可拖动、缩小和关闭的 Agent，修改限定范围内的内容，并支持撤销。

## 2. 大纲 → 智能演示

只上传 `星澜智造_智能演示大纲.pptx`。配图通过平台素材库或生成取得，不要求提前提供整套图片。

Agent 在右侧整理大纲、逐页讲稿和素材方案；可修改内容、顺序、图片及生成描述。点击“按此方案生成作品”后生成缺少的配图和逐句配音，完成后仍留在右侧播放成品，自行选择是否继续编辑。手动新建保留表单流程，模板选择支持预览或“无”。模板实际参与布局与样式。

编辑器在同一份作品内提供三个模式：

- **页面制作**：内容、设计、素材；编辑文字、位置、大小、背景和图片/视频，增加、复制、排序或删除页面。
- **讲解编排**：编辑逐句讲稿、停顿与语速，真实试听；为讲稿句子关联高亮、圈注、下划线，设置页面转场并查看时间轴。
- **互动问答**：设置整份演示/当前页回答范围、是否使用上传参考资料、补充资料和推荐问题；设置元素热点，用于提问、详情或跳页，并试问。

同一播放器使用这些设置。提问时暂停讲解，回答后继续；修改句子后旧配音失效，未修改句子可复用。顶部机器人入口随时调用 Agent，保留当前编辑上下文。

PPTX 导出包含页面内容、图片与备注讲稿；在线问答、语音和互动热点由平台播放器提供。当前没有外部知识库接入，也不承诺任意 PPT 文件的像素级还原。

## 3. 创意或脚本 → 互动影片

首页“互动故事”默认只提供创意，不附整套图片视频。也可以上传精简资料包中的可选策划脚本。

Agent 在右侧生成策划脚本、角色场景、节点和分支，用户确认节点、选项去向、素材形式和画面描述。场景节点可以先生成参考图，再生成 5 秒视频；其他节点默认图片，也可逐节点选择。生成后先在右侧体验最终故事，再按需进入节点画布。

节点可双击打开详细编辑，修改剧情、图片/视频/HTML、选项与目标节点。顶部 Agent 可修改已有节点和连线，不支持的新增/删除节点要求会明确拒绝；手动新增节点仍可使用。有效图校验阻止无效引用、循环及不可达结局。

真实视频走万相异步接口，持久化任务与 MP4；中断后复用原任务查询，不以预置样片代替生成。素材不足时显示实际状态。拍照、换脸等未接入能力不会仅凭脚本文字自动实现。

## 4. 组件生成与 21st 组件复用

首页“成果卡片组件”可以根据需求生成可编辑 HTML 组件包，检查、预览试编辑后入库。组件通常是包含 HTML、依赖及素材的 ZIP，上传流程保留整个包。

本轮另提供两款基于 21st 真实源码适配的组件：里程碑时间轴、悬浮卡片。包内保留上游源码和来源说明，运行版本为自包含 HTML，卡片缩略图来自同一运行版本截图。可预览、试编辑开放参数、保存副本、下载 ZIP，并插入已有或新建交互页面。对应文件位于 `public/components-catalog/`。

当前参数编辑限于已适配并公开编辑字段的组件，不等于任意 HTML 或第三方库都能无损转换成原生画布对象。来源及适配边界见组件包 README。

## 素材生成与数据边界

- 图片/视频提示词合并当前设计风格和本原型约定的华院展项制作规则：主次清晰、排版留白、同作品视觉一致，概念画面不冒充客户真实照片、资质或数据。这不是完整正式品牌 VI 的自动执行器。
- 图片生成前可编辑描述，生成后可放大、采用、替换和生成新版本；支持描述驱动的整图重生成，不宣称局部涂抹精修。
- 正文解析支持 TXT、Markdown、CSV、JSON、DOCX、PPTX；不支持的格式明确显示未解析。目录保留相对路径，组件与 Skill 文件夹整体打包。
- 图片绑定按文件名、资料说明与人工确认完成，未额外接入图片视觉理解。
- 只使用当前可访问且允许相应用途的素材，缓存按空间与内容槽位隔离。密钥仅在本地服务读取，不进入前端和导出包。
- 当前服务是本机单用户原型，不是已经部署的多用户生产权限系统。
