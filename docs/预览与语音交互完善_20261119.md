# 预览、Agent 排版与语音交互完善

本次沿用现有原型界面，完成已确认的交互调整。

## 参考、素材与返回

- 「添加参考展项」展示实际画面缩略图，支持放大、多页切换和试运行；仍可分别选择引用范围与参考维度。
- 从 Agent 创作成果进入运行预览，返回恢复对应创作界面；从编辑器进入则返回编辑器。
- 交互页面编辑器素材栏保留「当前空间」「共创社区」；空间绑定的演示素材按实际归属展示，通用素材仍可通过素材库入口选择，未删除原资产。
- 交互页面、智能演示、互动影片、视频分镜及参考展项试运行使用统一全屏入口；退出全屏不重新开始播放。

## Agent 重新排版

在助手中选择「当前页面」或「整个作品」，输入「重新排版整个页面」等明确的单一排版要求，可直接应用本地规则排版，并撤销本次调整。

排版调整标题、图文区域、间距及时间轴位置，保留内容、素材、交互和元素标识。锁定、隐藏、旋转及装饰形状保持原状；空间不足时保留原布局。HTML 组件只调整容器，不改写其内部内容。复杂混合要求继续交给模型，界面会明确区分「本地规则排版」与模型处理。

「整理制作经验」读取所选范围的成果、参考关系和已应用修改记录，整理做了什么、参考了什么、作了哪些调整、可复用做法与尚待验证内容。演示模式使用本地规则，DeepSeek 模式调用模型；整理结果可修订、保留版本历史，再由使用者确认提炼为未启用的 Skill 草稿，不会自动变成已验证规则。

## 智能演示的语音

观众操作流程：提问 → 暂停当前讲解 → 录音 → 结束录音 → 核对识别内容 → 确认提问 → 播报回答 → 点击继续讲解。旁白与回答使用独立音频，继续讲解保留原进度。

录音采用浏览器 SpeechRecognition，需浏览器支持并允许麦克风；不支持、拒绝权限或转写失败时有明确提示与文字辅助输入。知识问答仍遵守作品配置的资料范围；ACP 演示绑定仍为模拟，不代表已连接真实 ACP 服务。

在「讲解编排 → 配置声音」统一设置整份作品的讲解与回答声音：

| 设置 | 本次状态 |
| --- | --- |
| 专业讲解男声音色 | 使用现有接口已提供的 speaker |
| 自然专业、亲切讲述、庄重汇报 | 通过已提供的 context_texts 参数设置语气 |
| 语速 | 播放速度 0.5–2 倍，可试听 |
| 音调 | 接口未提供，明确禁用 |
| 声音克隆 | 可选择、上传并保存样本引用，显示待接入；不冒充克隆成功 |

切换声音语气后旧句子配音会失效，重新生成采用新参数；仅调整播放语速保留原配音。声音克隆样本不会影响当前讲解音色。
