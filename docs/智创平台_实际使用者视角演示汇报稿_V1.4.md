# 智创平台 · 实际使用者视角演示汇报稿

适用版本：当前 V1.4 Demo。以策划、设计人员完成一次内容生产为主线，讲清三类创作项目、素材复用与团队共创，兼顾开发指导、产品汇报和实际操作说明。

使用方式：正文可直接口述；【操作】只用于提醒演示者，不用念出来。口述建议控制在 20 分钟左右，配合操作预留约 25–30 分钟。主线采用钢铁企业示例，不对应真实客户事实；实际时长以口述速度和页面停顿为准。

---

【操作：停留在登录页，开始介绍。】

今天我想从我们策划和设计同事实际工作的角度，介绍一下智创平台。

假设我现在接到一个企业展厅项目，需要把客户给到的介绍、发展历程、案例和图片，做成观众能够实际操作的展项。这里面会涉及内容梳理、形式选择、素材制作、交互配置，以及最后的交付。

智创平台希望把这几个环节衔接起来，让策划更容易把需求变成初稿，让设计能够继续精修，也让已经做过的成果在下一个项目中接着使用。

它主要服务交付阶段的内容生产，也支持售前快速验证想法、展示展项效果。这次我们用高保真 Demo，把这条生产链路实际走一遍。编辑、保存、复用等操作可以体验，AI 理解和生成部分目前使用预设场景演示。

【操作：使用 jiming / 123456 登录；展开空间选择，展示后回到个人空间。】

登录以后，我先确认这次工作放在哪个空间。

个人空间适合自己准备方案、试验想法。针对具体项目开展创作时，可以进入“信泰企业展厅”“东莞博物馆”或者“ai小镇展厅”这样的项目空间，把作品和素材按项目组织起来。产品规划上，这也对应一个项目中若干成员共同工作的范围。

今天先在个人空间里，用平台准备好的示例走一遍。左边只有首页、项目、素材库、Skills 和共创社区五个主要入口，也可以收起侧栏。最近草稿能继续打开作品、找回未发送的需求和创作任务；内容多了以后，也能通过搜索快速找到。

这里先区分两个概念：空间是我们围绕客户项目共同工作的范围；在空间里，每做一份交互程序、一套讲解演示或者一部互动影片，都会形成一份可以继续编辑的项目。点击“新建项目”创建的是这份作品，不是另建一个协作空间。

【操作：如输入框已有“同款创作资料包”，先点击旁边的叉号移除，再点击“企业发展大事记”，保留预填需求；依次点开回形针、模型、设计系统和 Skills 入口，先不发送。】

现在我作为策划，要为一家钢铁企业做发展大事记。我可以直接用日常语言说明：希望按年代浏览，点击事件能看图文详情，适配展厅里的全景屏，整体风格稳重一些。

如果手里有客户资料、图片或者参考效果，可以通过回形针一起放进来，让需求和资料跟着同一次创作走。

下面可以选择 GPT、Claude、DeepSeek 等大模型；具体需要用到哪些创作能力，由平台根据任务来编排。旁边还可以选择设计系统和 Skills。

首页的文字提示，帮助我快速说清常见需求。除了完整展项，也可以从背景图片、讲解视频、交互组件或者 HTML 交互内容开始。如果还没想好形式，也可以先描述要展示什么，再逐步明确方向。

【操作：保留首页需求，进入“共创社区 → 设计系统”，打开“工业蓝”；展示后返回社区，切到“Skills”，打开“企业大事记编排”，查看后添加到个人 Skills，再返回首页。暂不点击“带入首页使用”，以免改变主线需求。】

在发送之前，我先把风格和制作方法说明白。

设计系统集中放在共创社区里，由开发团队维护共用的设计语言。先看到的是不同风格的效果预览，比如工业蓝、科技风、政务风和人文典藏。点进某一种以后，才是它对应的颜色、字体、排版、组件和动效规范。

对一个展厅项目来说，这可以帮助不同展项保持一致的视觉语言。它既能用于新的创作需求，也能应用到已有作品上。如果暂时不想限定风格，选择“无”就可以继续创作。

Skills 则是把团队常用的制作方法保存下来。比如怎么组织时间轴内容、怎么制作一个语音气泡，或者怎么形成某种风格的背景。

每项技能都有预览和用途说明，可以查看需要提供什么资料、会按什么步骤处理，再带着自己的需求启动。社区里的技能可以先“添加到我的 Skills”，也可以直接带入首页使用。采用的是一个固定版本，社区后来更新了，不会悄悄改变我正在使用的方法。

左侧 Skills 管的是自己的技能包和已经添加的能力。我们自己的方法，也可以整理成 ZIP 上传，把说明、参考资料和预览一起保留下来。满意之后再提交审核，通过才发布到社区，供其他同事采用。这样，下次遇到类似任务，就有方法可以沿用。

【操作：返回首页，确认原需求仍在；按需选择“工业蓝”和相关 Skill，发送。等待“确认创作资源”，先展示候选及来源，再点击“生成并继续”。】

需求发出去以后，页面会把创作过程展示出来。

这里的生产逻辑是，先理解我要做什么，再检查团队已有的组件、素材和模板能不能满足要求。已有的资源可以直接复用，需要补充的部分再进入生成流程。

比如现在，时间轴的结构和交互可以沿用。平台先把符合要求的背景列出来，让我看到效果、来自哪里、为什么匹配。如果其中有合适的，可以直接选；如果这些效果都不合适，或者没有找到候选，再生成新背景，也可以自己选择或上传图片。

组件也有不同情况。平台已经适配好的语音气泡、时间轴、卡片，可以生成配置后继续编辑。全新的特殊组件，需要按组件协议开发和适配；目前可以先用交互程序示例表达效果、调整外层位置和尺寸，内部能力再交给开发接入。

这样，策划能够看见当前完成了什么、还需要补什么。任务也可以暂停、继续，异常时保留已有进度再重试。

现在可以看到，背景补齐以后，主成果展示的是完整展项，原来的文字、时间轴和交互都在。新增背景在下面单独展示，也已经进入素材库。

【操作：在成果页依次发送“把背景改成暖色”“增加一个 2025 年节点：全球布局”；观察变化，再撤销一次。】

有了第一版之后，我通常还会继续调整。

比如我觉得背景需要暖一点，就直接说“把背景改成暖色”；还缺一个发展节点，再补一句“增加一个 2025 年节点：全球布局”。

这两次修改都接着当前作品往下做，前面的内容会保留下来。修改范围也可以指定为整个作品、某一页，或者某个组件。

旁边可以看到修改记录，不满意就撤销。需要替换图片时，也可以上传新图片继续提要求。它让策划和设计能够围绕同一份成果，逐步把内容完善，而不用每次都从一份新的初稿重新开始。

【操作：点击“继续编辑”。选择标题并拖动；切换“图层”；展示页面栏。右侧依次切换“属性、交互、动效、命令、AI”，最后在 AI 中选中文字，输入“把文字改为创新的足迹”。】

方向确认以后，我再切换到设计人员的工作方式，进入画布做精细调整。

左边是组件、素材和图层。文字、图片、视频、音频这些基础内容，以及时间轴、照片墙、关系图谱、地图、数据图表等复合组件，都可以从这里选择。已经适配并沉淀下来的组件，也可以继续拿来使用。

中间是实际画布。我可以拖动位置、调整尺寸、复制组件、管理图层和页面，让内容适应现场屏幕。原生展项里的内容保留了可编辑结构，设计可以接着往下做。

右边围绕当前选中的对象展开：属性负责内容、布局和外观；交互负责点击以后显示什么、跳到哪里；动效负责内容怎样进入和切换；命令负责配置展项响应哪些语音口令，目前可以输入口令进行模拟测试。

AI 助手也保留在这里。我选中标题以后，就可以直接要求修改这段文字，或者在选中图片后替换素材。手动精修和对话修改，可以在同一件作品中衔接起来。

这里换素材也不需要跳出画布。我可以在左侧“素材”中预览、拖入图片和视频，也可以选中已有组件，从属性面板打开素材库替换。当前项目的素材、社区的素材和内置素材，会分开展示来源；替换以后，原来的位置、尺寸、动效和交互继续保留。

编辑过程中有保存、撤销和重做，预览回来也会保留当前的编辑位置。左右面板都能用双箭头收起，需要回首页时点击左上角 Logo。已发送的需求会清空，尚未发送的内容继续保留。

【操作：点击“运行预览”，点击时间轴节点打开详情，再返回编辑；展开“导出运行包”菜单。】

接下来，我会站在参观者的角度体验一遍。

比如这里点击一个年份，可以打开对应的图文详情，再返回继续浏览。设计人员就能检查内容是否清楚，点击关系是否正确，页面切换和动效是否符合预期。

确认以后，再选择交付方式。这里提供浏览器自包含运行包、展项播放器离线包，以及播放器在线清单三个方向。

当前 Demo 的浏览器运行包可以实际下载，解压后离线体验。播放器相关的两种格式，现在用于表达交付流程和协议结构，后续还需要对接真实播放器。

到这里，我们就完成了从需求、初稿、修改，到可运行展项的一条主生产链路。

【操作：返回首页，打开“新建项目”，展示交互程序、演示与视频、互动影片三个入口；选择交互程序，展示空白/模板两种起点，再进入空白设置，展开展示形式和分辨率。通过“上一步”返回并关闭。】

日常工作里，我们也会遇到已经有明确方案的情况，所以平台把制作入口统一放在“新建项目”里。

第一类是交互程序，用来制作能点击、浏览、探索的内容；第二类是演示与视频，用来编排讲解页面和视频分镜；第三类是互动影片，用节点和分支来组织观众可以参与的故事。后面我会把另外两种制作方式也演示一下。

现在选择交互程序，就能继续从空白画布开始，填写项目名称、展示形式和屏幕分辨率；也可以从模板开始，直接进入已经筛选好的社区模板。

这里的时间演进、关系图谱、卡片浏览、空间分布、流程架构、媒体叙事和数据总览，是交互程序的七种展示形式。屏幕可以是常规横屏、竖屏、方屏、全景屏、超宽屏，也可以自定义尺寸。暂时没确定内容用途，不影响先创建。

这样，策划可以从需求开始，设计也能按照自己的熟悉方式直接搭建；不管从哪里开始，成果都保留为可以继续编辑的项目。

【操作：进入“项目”，展示搜索、筛选及卡片更多菜单；再进入“素材库”，打开一项素材详情。】

作品逐渐多起来以后，就需要把它们管理好。

项目里统一管理三类创作工程：交互程序、演示与视频、互动影片。演示页面和讲稿、视频分镜、故事节点都保留在项目里。从这里打开哪一份作品，就回到它对应的编辑器。

查找的时候，我可以先按这三大类筛选，再按“展示什么内容”来找，比如发展历程、荣誉资质、案例成果、产业布局或者产业链。这一组叫内容用途，贴近策划整理资料的方式。展开“更多用途”，还可以看到企业概览、产品与服务、技术创新、工艺流程、经营数据、文化人物、文博科普等，共十二项。

如果选择交互程序，还能进一步按时间轴、关系图谱等展示形式筛选。一个回答“展示什么”，一个回答“怎样展示”，这两个维度可以组合使用。

项目也可以按名称和时间查找，进行重命名、复制、预览和继续编辑。确定要移除的作品可以删除，三类工程都能从项目回收站恢复，最近草稿也有快捷删除入口。

素材库管理制作中用到的文件和组件，包括图片、视频、音频、组件和文档资料。HTML 内容归入嵌入式组件，上传的 PPT 等资料归到文档；它们都可以预览和复用。

这里最直观的区别是：还要继续改页面、讲稿、分镜和节点的，去项目找；要给作品换一张图、插入一段视频或者采用一个组件的，去素材库找。以后真正生成的 PPTX、成片 MP4 也作为文件放入素材库，原来的工程仍然保留。

当前 Demo 还没有真实生成 PPTX，也没有把修改后的分镜重新合成为 MP4。我们会把工程、预置样片和实际文件分别说明，让后续开发清楚每一步需要交付什么。

【操作：打开自己的图片素材，切到“素材信息”，展示业务说明、适用对象、用途和智能体调用开关。】

自己上传的素材，怎么让智能体找得准，也是这里需要解决的问题。文件格式、尺寸等客观信息由系统读取；内容说明可以沿用原有信息，也可以补充。比如这张图片，我可以说明是客户的工厂实拍、适合放在哪些页面，并确认它属于哪一家客户。

业务身份由使用者确认，不能仅凭文件名猜。暂时没有说明的素材会标为待补充；只想用作参考，或者不想让智能体自动选取的素材，也可以设置用途或关闭调用。这些说明同样支持搜索。当前 Demo 用规则演示匹配过程，未来再接入自动图片理解。

自己的素材留在当前空间，只有提交审核后才进入共创社区。采用社区素材时，会在当前空间留下带来源和版本的副本，之后可以按项目修改，不影响社区原版。画布和智能体沿用这套关系，避免素材在不同入口里各管一份。

【操作：打开“共创社区”，展示四个板块；在“展项模板”选择“交互程序”，按内容用途筛选，打开详情并点击“快速复用并编辑”。返回社区，切到“展项素材”，打开完整资料，再点击“一键同款”。】

如果团队已经做过类似内容，我会先到共创社区看看。

这里有四个板块：展项模板、展项素材、Skills 和设计系统。

先看展项模板。这里也按交互程序、演示与视频、互动影片三大类组织，和项目列表保持一致。我可以按内容用途寻找企业历史、荣誉、案例等内容，再看效果、结构和作者信息，合适的就收藏或者快速复用。

复用后创建的是一份独立项目，交互程序回到画布，演示或视频回到各自的编辑器，互动影片回到节点工作台。我替换自己的内容就能继续做，原作者的作品会保留。

再看展项素材，比如一张背景、一段视频、一个组件，或者一个可嵌入的 HTML 效果。HTML 没有另设一大类，而是按组件来找；演示的可编辑工程则到模板里复用。

这类内容除了效果本身，还会保留背后的资料：用了哪些文件、什么提示词、什么参数，以及关联了哪些 Skills。

点击“一键同款”以后，这些信息会一起带到首页的新草稿里。我再补充自己的主题和要求，沿着已有方法继续生成。原来没发送的需求也会保留。

Skills 和设计系统这两个板块，就是刚才看到的制作方法与视觉规范。前者支持个人上传、审核共享和固定版本采用；后者由开发团队统一维护，使用者按需要选择。

所以，完整项目可以作为模板直接复用，素材可以带着资料包再创作，技能和设计系统则帮助团队沿用成熟的方法与风格。四类内容有不同作用，共同支持下一次生产。

【操作：从项目卡片更多菜单选择“提交到共创社区”，确认项目大类、内容用途和展示形式，填写用途说明并勾选使用范围，再点击“提交审核”。通过账户菜单进入“审核管理”，打开该投稿，完成内容、资源、交互检查，点击“通过并发布”。如已准备自己的 ZIP 技能，再展示自有 Skill 的投稿入口，不必重复整段审核。】

当我自己做出了一份值得复用的内容，也可以反过来贡献给团队。

三类项目都可以提交为展项模板，素材和自己的 Skill 也可以投稿。项目投稿时，我再确认这份内容适合什么用途；如果是交互程序，也确认展示形式，让其他同事以后更容易找到。

提交后先进入待审核，由管理员检查内容是否准确、资源是否完整，以及交互是否可用。技能还要检查说明、输入输出、示例和依赖文件。设计系统由开发团队维护，不走个人投稿流程。

有问题可以退回，并写清楚修改意见；通过以后，才会出现在社区里。创作者也能查看投稿进度，或者撤回还没有发布的内容。

这里发布的是审核过的那一版。之后我继续修改个人草稿，不会直接把社区里已经发布的内容覆盖掉。

这样，从项目里产生的好成果，就能经过整理和校对，逐步成为团队下一次生产的起点。

【操作：切回个人空间，点击“新建项目 → 演示与视频”，打开“讲解演示”中的“企业创新成果讲解”样例，展示页面和讲稿，再开始演示，暂停、文字追问并继续。】

同一个项目，往往还需要配套的讲解内容。

比如客户除了让观众自己触摸浏览，还希望有人把企业的发展、技术和案例完整讲一遍。这时就从“新建项目”进入“演示与视频”，选择讲解演示。原来 AI 演示中心的能力，都在这里继续使用。

这里可以从主题或已有资料出发，先整理大纲，再形成页面和讲稿。策划可以调整讲述顺序，设计可以修改画面，讲稿也能继续完善。

演示时可以播放、暂停、显示字幕，也能展示文字追问后继续讲解的过程。当前用预置音轨和示例问答来演示这种体验，后续再对接真实配音和知识问答能力。

它承接的是同一批内容的另一种使用方式：既能帮助展厅接待，也能用于方案讲解和客户沟通。

完成后，这份页面与讲稿工程保存到“项目”的“演示与视频”里。以后可以从工作台的最近创作进入，也可以从项目里打开，回到同一份页面和讲稿，不用在不同入口重复维护。当前能导出工程 JSON，真实 PPT 文件生成属于后续接入能力。

【操作：返回“演示与视频”工作台，切换“视频创作”，打开“面向未来 · 品牌短片”样例，展示分镜、旁白、时长和预览；点击“查看项目”展示工程归属。】

如果需要的是开场短片，或者一段有固定节奏的讲解视频，就切到视频创作。

这里把内容拆成分镜，逐段安排画面、旁白和时长，再预览整体节奏。策划和设计可以先把“讲什么、怎么讲”确认下来，并保存当前创作工程。

保存后，视频工程也进入“项目 → 演示与视频”。预览对应当前的分镜和字幕，我可以随时返回继续调整画面、旁白文案和时长。

当前版本已经能演示分镜编排和预览，完整的视频合成还需要接入后续能力；页面里的预置样片，用来说明最终播放效果。演示文稿目前保存的也是可编辑工程，后续再接入真正的 PPT 文件生成。

【操作：点击“新建项目 → 互动影片”，打开“未来工厂探索之旅”，展示场景和分支节点，点击“检查流程”“试运行”，体验一条分支。】

再往前一步，如果希望参观者自己做选择，让不同选择带来不同体验，就选择互动影片。这里沿用造梦机的节点创作能力，现在和另外两种形式放在同一个新建入口里。

它采用节点工作流来搭建互动故事。一个节点可以是一段场景，也可以是一次选择；节点之间的连线，决定接下来进入哪段内容、满足什么条件、走向哪个结局。

比如在这个未来工厂示例里，观众可以选择了解绿色材料，也可以去探索数字制造。我们可以修改剧情、替换素材、调整分支，再检查流程并实际试运行。

这份成果保存在“项目 → 互动影片”里。下次从项目打开，就直接回到节点画布，接着修改原来的故事和分支。场景中使用的图片、视频仍然从素材库选择，工程和媒体文件各自保留。

从使用者的角度，先决定这次要制作哪一种内容，进入相应工具，之后所有可编辑工程都到项目里找，制作时需要的文件和组件都到素材库找。这样，同一个展厅空间里，就可以根据内容需要，组织触摸浏览、讲解演示、视频或者互动故事等不同表达方式。

【操作：返回首页，结束汇报。】

回到我作为使用者的这一天：先带着需求和资料进来，借助已有资源和 AI 形成初稿，再通过多轮交流和画布编辑完成修改；体验确认以后交付，好的作品和制作方法再经过审核，留给团队复用。

对于策划，希望减少从资料到初稿的距离；对于设计，希望保留足够的编辑能力，方便把控最终效果；对于团队，希望每次交付都能留下下一次用得上的东西。

这份 Demo 也把页面、操作和成果之间的关系具体呈现出来，后续可以直接围绕这些流程讨论开发、分阶段接入现有能力，并用真实项目持续验证。多人协作、真实模型和生成服务还需要继续整合，但我们最终要让这条链路能够承担实际的内容生产。
